## 设计出发点

采用“一条剧情主干＋几条可自由推进的成长支线”。飞船维修作为序章，完成后自然转向探索宇宙和寻找故事线索。

参考《星界边境》让沙盒探索产生线索、再引向剧情任务的方式，同时允许装备、建造和支线成长相对独立。任务提供方向，玩家保留游玩节奏的选择。

参考资料：[Starbound 官方开发日志：29th February — Clueless](https://community.playstarbound.com/threads/29th-february-clueless.107286/)。以下具体任务均为本项目讨论中的原创提案，不是原作任务清单。

## 整体任务树草案

```text
序章：余烬中的苏醒
  重建联络 → 第一次地表行动 → 恢复亚光速航行
                    ├─ 工具支线：采集、体素、物质枪升级
                    └─ 生存支线：补给、避难所、地表据点
                                      ↓
第一章：熟悉这片星空
  第一次航行 → 另一片天空 → 发现异常信号
                    ├─ 探索支线：不同星球的独特发现
                    └─ 工程支线：改善远征准备与设备使用
                                      ↓
第二章：失联的回声〔未来内容〕
  寻找信号源 → 调查遗址 → 取回航行记录
                    ├─ 调查支线：补全事件真相
                    └─ 挑战支线：危险区域与额外战利品
                                      ↓
第三章：跨越恒星〔未来内容〕
  寻找跃迁技术 → 修复超光速引擎 → 首次跨星系航行
                                      ↓
后续章节：文明接触、阵营故事、宇宙深处的谜团
```

支线可以跨章节延续，不要求全部清完才推进主线。

## 序章：教会玩家活下来，然后离开起点

| 任务 | 玩家实际行动 | 建议奖励（未定） |
|---|---|---|
| 重建联络 | 完成 NOVA 开头通讯，了解处境 | 开启后续指引 |
| 第一次地表行动 | 使用传送器亲自抵达地表 | 物质枪模块 ×1 |
| 手中的工具〔支线〕 | 用物质枪完成一次基础采集 | 少量补给 |
| 重构物质〔支线〕 | 收集体素，了解打印机用途 | 设备使用档案 |
| 更深一层〔支线〕 | 获得升级工作台并完成一次采集能力升级 | 少量补给或模块 |
| 恢复亚光速航行 | 制作点火核心，安装到飞船引擎并完成点火 | 物质枪模块 ×1；获得实际航行能力 |

“恢复亚光速航行”内部显示准备步骤即可，不必把每颗钻石、每次打印都拆成独立任务。玩家提前做完的事情应自动认可，NOVA 用文字说明操作地点。

工具支线提供帮助；多人游戏里，其他船员已经修好引擎时，个人升级也不应成为重复维修的门槛。

## 第一章：让探索具有目的

“另一片天空”的到达判定适合作为入门任务；长期探索则需要不同星球提供不同体验。

| 任务 | 设计内容 | 作用 |
|---|---|---|
| 第一次航行 | 在星图选择目的地，完成一次航行 | 学会使用星图 |
| 另一片天空 | 抵达另一类星球地表 | 从起始星球走向宇宙 |
| 行星调查〔分支〕 | 根据星球特点完成一个具体发现 | 形成各类星球的记忆点 |
| 不属于这里的信号 | 探索途中发现异常设施或记录 | 将自由探索引向第二章 |

行星调查的候选内容：

- **繁茂星球：生命的痕迹。** 发现特殊生态地点，带回一种研究样本。
- **荒芜星球：尘埃之下。** 找到被埋没的人工设施，取回残存记录。
- **冰冻星球：冻结的回声。** 找到冻封装置，调查它为何仍在运行。
- **熔融星球：热流深处。** 深入危险区域，取得耐热材料或工程样本。

这些内容需要后续补充地点、物品和交互。讨论中的建议是先做一个完整探索事件，再扩展其他星球。主线只要求完成一个可用分支，其他分支提供奖励与背景，避免强迫玩家按固定顺序遍历所有星球。

## 第二章：给玩家一个值得追下去的问题

候选悬念（未确认的剧情设定）：

> NOVA 在陌生星球上收到一段带有本舰识别码的求救信号，但它的发送时间早于飞船抵达。

它可以把飞船、NOVA 与外部世界联系起来，无需让 NOVA 再次离线或故障。

候选任务顺序：

1. **循迹而行**：根据线索寻找信号源，明确提示目标环境与可识别特征。
2. **无人应答**：调查废弃中继站，通过场景了解发生过什么。
3. **最后一次传输**：完成一次有特色的行动，例如恢复局部供电、突破封锁或取回记录。
4. **星图之外**：发现位于当前航行范围之外的坐标，引出超光速引擎修复。

关键节点可奖励独特物品、能力或新目的地；普通调查奖励补给和档案。避免所有任务最终都只发物质枪模块。

## 长期成长支线

| 支线 | 主要体验 | 与主线的关系 |
|---|---|---|
| 物质枪研究 | 采集、升级、使用新能力 | 帮助探索，奖励适量模块 |
| 远征准备 | 食物、装备、危险环境准备 | 降低远征难度 |
| 地表建设 | 建立据点、布置补给、改善生活 | 服务喜欢建造的玩家 |
| 行星档案 | 发现地点、生物、材料与遗迹 | 提供收藏目标和世界背景 |

殖民地、船员、阵营委托等可以以后扩展，不必提前塞进当前任务列表。

## NOVA 中的呈现构想

沿用讨论中的四页结构：

- **总览**：一个当前主线目标、最多两个推荐支线，以及待领奖励。
- **任务**：按章节和支线分组，查看目标、步骤、奖励与追踪状态。
- **档案**：保存发现与操作知识，承载较长的世界观内容。
- **通讯**：呈现剧情对话和 NOVA 对当前任务的解释。

左下角 HUD 用于到达提示、重要发现和任务完成通知；同一段旅程里避免每完成一个小步骤都弹出一轮讲话。无需常驻 NOVA 在线状态。

奖励领取与任务解锁分开：完成目标后可以继续探索，奖励稍后回终端领取，减少往返打断。终端通过文字引导玩家前往对应设备，不远程调用打印机制造或安装。
