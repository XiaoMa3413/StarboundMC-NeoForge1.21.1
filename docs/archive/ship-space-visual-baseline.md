# 飞船维度太空渲染基线归档

> 状态：已实现基线归档，不在本文继续追加新任务
>
> 归档日期：2026-09-02
>
> 核对基线：`codex/nova-prologue` / `eefcc33`

## 文档目的

本文记录飞船维度已经具备的太空渲染能力，避免后续美化工作重复实现既有功能。当前代码、测试与
实际游戏画面始终优先于本文；新的视觉需求统一记录在
[飞船维度太空视觉增强计划](../ship-space-visual-enhancement-plan.md) 中。

## 已实现的空间背景

- 飞船维度使用 `SkyType.NONE`，不叠加原版太阳、月亮和星空；`PlanetRenderer` 完整接管天空、
  星点、恒星、行星和跃迁演出。
- 已有一个包围视野的深蓝至近黑色太空穹顶，确保任意视角下都有稳定的深空底色。
- 已有 2000 颗固定种子的程序化背景星。星点具有大小、亮度、冷暖颜色和轻微闪烁差异，重新进入
  世界后分布保持一致。
- 背景星会跟随飞船的虚拟航向旋转；渲染使用去除行走视角晃动的稳定相机姿态，玩家在舰桥内走动
  不会让远方天体产生不合理抖动。
- 当前背景星仍位于同一个远景壳层，分布整体接近均匀；尚未实现星云、尘埃带、星团或普通航行时
  的远近视差。

## 已实现的行星渲染

- 行星位置由统一宇宙坐标和飞船虚拟位置计算，而不是固定贴在屏幕上；远距离行星按角尺寸投影到
  安全的天空壳层。
- 行星使用共享的 `32 × 64` UV 球体几何、各天体的球面贴图和固定恒星入射方向，因此已经具有
  球体轮廓、明暗面和稳定的空间朝向。
- 行星按距离从远到近绘制，并具有按天体区分颜色和强度的大气边缘辉光。
- 行星与恒星共享同一套虚拟航向变换，转向、亚光速航行、抵达淡入和停靠画面之间不会采用互相
  矛盾的坐标规则。
- 四张行星球面贴图已经达到 `4096 × 2048`；现阶段的限制并非贴图分辨率不足，而是表面方向完全
  固定、光照颜色烘焙在缓存顶点中、所有大气都采用相近的单层均匀辉光，也没有云层、海洋反光、
  熔岩自发光等按行星类型区分的材质表现。

## 已实现的恒星渲染

- 恒星由真实星系位置和距离响应计算可见性、投影尺寸、亮度、日冕细节和环境影响，不依赖硬编码的
  “当前星系专用画面”。
- 已实现 `POINT`、`SIMPLIFIED`、`FULL` 三级 LOD 及平滑权重过渡：远景恒星批量绘制为星点，中景
  绘制为简化圆盘和辉光，近景绘制完整日冕、辐射弧、星芒、粒子和脉动。
- 性能预算限制为最多 3 颗 `FULL` 恒星和 16 颗 `SIMPLIFIED` 恒星，其余恒星继续走批量星点路径。
- 不同恒星通过 `StellarVisualProfile` 区分表面色、核心色、日冕色、辐射强度、耀斑和脉动参数。
- 当前所谓 `FULL` 指“完整特效层级”，恒星核心本身仍是始终朝向相机的二维圆盘，并不是像行星
  一样的真实球体；这正是后续 3D 恒星原型要解决的问题。

## 已实现的连续星系环境

- `StarSystemResolver` 根据飞船位置连续计算附近星系影响，不会只因星系 ID 改变而硬切画面。
- `GalaxyEnvironmentBlend` 已输出天空染色、辐射强度、环境存在感和主导星系等连续参数。
- 当前普通星空已经使用环境颜色进行轻微混色；环境数据也为未来的星云密度、尘埃颜色、环境音和
  辐射表现预留了统一来源。
- 现阶段环境影响主要停留在星点染色，尚未充分改变太空背景的结构、密度和层次。

## 当前星系尺度

- 第一、第二恒星系的导航中心目前相距约 `14,988` 虚拟空间单位；两者影响半径分别为 `5,500` 和
  `4,500`，两个影响范围之间只有约 `4,988` 单位的纯深空间隔。
- 从初始翠绿星球停靠区域观察，第一恒星系主星约在 `24,478` 单位外，第二恒星系红矮星约在
  `26,016` 单位外。两颗恒星对玩家来说接近同一距离层级，因此第二星系容易显得像紧邻的天体，
  而不是需要超空间航行才能抵达的遥远星系。
- 深空星图使用独立的美术坐标：两个系统当前位于 `250 × 220` 基准画布的 `(62, 84)` 与
  `(182, 129)`。该坐标不会自动反映真实宇宙距离。
- 当前跨星系航线按距离计算约为 546 tick，即约 27.3 秒；长航线时长上限为 560 tick，即 28 秒。
  因此未来拉大真实坐标不会明显延长现有跃迁等待时间，除非另行修改航行时长规则。

## 已实现的跃迁演出

- 长距离航线已经包含转向、星点向航向汇聚、进入超空间、减速、抵达淡入和回正过程。
- 跃迁隧道包含中层、近层、边缘层和环绕层的流动光迹，具备明显的空间纵深，而不是单层放射线。
- 已有消失点核心辉光、短促的入场闪光、目标天体颜色混合以及与权威飞行时钟同步的运动节奏。
- 短距离亚光速航线不会错误进入超空间隧道；已经确认的跃迁视觉不列入本轮重做范围，只允许在新
  背景接入后微调淡入淡出衔接。

## 基线结论

后续工作的重点不是“重新做一套太空渲染”，而是在保留现有统一坐标模型、LOD、行星和跃迁体系
的前提下，重新校准两个星系的空间尺度，补足普通状态下的背景纵深，并把近距离恒星核心从二维
特效圆盘升级为受性能预算约束的自发光球体。
