# EPP 环境生存实施计划

基线：`codex/epp-mechanisms` / `e11661e`。2026-09-18。

依据《StarboundMC EPP、个人机动装备与环境生存系统设计》及本次对话确认。
本文件记录实施决策和实际验证；设计文档中与下列确认冲突的建议不作为施工要求。

## 已确认的范围（R0–R5 历史基线；后续授权见 R6）

- 本轮执行 R0–R5：Mk.I、独立装备槽、有限氧气、补给设备、氧气罐、月球补给与引导。
- Mk.I 在 Lush 即可制作，不要求 Barren 专属核心。新增通用基础电路板（Circuit Tier 0），
  用于 EPP、补给设备及其他基础科技。Barren 的高级元件、升级奖励留给后续阶段。
- Frozen/Molten 可呼吸，冷热与供氧独立。本轮不启用尚无防护装备可应对的冷热伤害。
- 普通可呼吸环境停止耗氧；默认飞船明确划定的舱内区域自动补氧。首版不检测拆墙失压。
- 玩家自行制作并摆放补给设备；不修改默认飞船模板。设备在有可呼吸空气处提供灌装。
- 独立 EPP 槽，不占胸甲；唯一 Active EPP，第三方槽位预留接口，无强制饰品依赖。
- 氧气随物品保存。允许携带和更换备用 EPP；模块安装限制留到 Mk.II。
- 死亡遵循 keepInventory，重登/换装不重置窒息缓冲。水下呼吸维持原版行为。
- 初始调参：Mk.I 720 单位，正常无氧环境每秒 1 单位；氧气罐 180 单位，使用 2 秒，
  受伤中断，只在能完整容纳时使用；满罐不堆叠，空罐叠 8；耗尽缓冲 10 秒。
- 不提交、不推送；用户原有未跟踪文档与 output/tmp 不纳入本轮整理。

## 验证矩阵

- 环境：月球无氧、Frozen/Molten 可呼吸、非目标模组维度不凭空增加危险；按玩家位置查询。
- 生命周期：换装、丢弃、交易、死亡两种 keepInventory、重连、正常重启、旧存档默认值。
- 服务端：多人分别耗氧；重复补给操作不复制物品；满槽、关闭菜单、断线和拆除设备安全。
- 氧气：无 EPP、耗尽缓冲、缓冲连续性、恢复呼吸、满容量限制、临界容量用罐、受伤中断。
- 客户端：中文/英文、GUI 缩放、装备/背包槽拖动、HUD 阈值和 NOVA 提醒不刷屏。
- 生存：Lush 材料到 Mk.I；飞船补氧；携带补给探索月球；只在指定前哨提供稀疏补给。

- 不启用 Heat/Radiation 伤害，不推进局部太空、EVA 或 Mobility Rig。
  延续已确认的 Mk.I 在 Lush 可制作、向上曲面 HUD 和微增惯性；不提交、不推送。

## 游戏内验收入口与剩余项目

1. 默认 **G** 打开个人环境装备页（可在控制设置更改），穿戴 Mk.I；胸甲槽保持可用。
   新制造的设备为空，在默认飞船舱内约 3 秒充满，或在有空气处打开补给站维护。
2. 从打印机制作基础电路板、Mk.I、补给站和空罐。普通 Lush 材料即可完成；
   基础电路板也用于新的工业灯打印配方，旧工业灯配方保留。
3. 将空罐放入补给站槽位，1 秒后取出满罐。离开/关闭界面不取消灌装。
4. **生存模式**前往月球，确认耗氧、低氧提醒、用罐需长按 2 秒且受伤会中断。
   创造/旁观者免除耗氧和窒息，不适合验收消耗速度。
5. 返回飞船补氧，检查 NOVA 两个新增任务、个人奖励及不同玩家的独立进度。
6. 待人工验证：中英 GUI 缩放、拖放与关闭界面、背负模型/动作、HUD 不遮挡、警告声音；
   真实客户端联机、退出重进和完整关服重启、旧存档中实际维度与新前哨补给。

自动测试中的存档验证是实际 Player/BlockEntity NBT 编解码往返，**不是**真实关服重启验收。
没有声称完整客户端联机或视觉测试已通过。Mk.II、模块、EVA、Jump Thruster 仍留在后续阶段。


### 氧气 HUD 与快速补氧调整

- HUD 简化为头盔曲面投影：只保留淡青色 O₂ 百分比与向视野右缘上扬的细弧线，读数沿曲面切线轻微倾斜；无底板、边框或常驻状态说明。补氧时弧线轻微呼吸，缺少 EPP、严重低氧与补氧时才显示短提示。佩戴 EPP 时持续显示，低氧危险状态保留暖色警示。
- 默认受控供氧从 24 提高至 240 单位/秒（默认 Mk.I 空罐约 3 秒充满）；补给站灌装从 100 缩短至 20 tick（1 秒）。手持氧气罐使用时间仍为 2 秒。
- 灌装进度显示按实际总时长换算百分比。既有外部服务器配置仍由服主控制，需手动将 `refillPerSecond` 更新为 `240`；本地 run 和 GameTest 开发配置的旧默认值已更新。
- 验证：`gradlew.bat compileJava test --tests "*OxygenRulesTest" --console=plain` 成功（8 项氧气规则单测通过）；`gradlew.bat -PshipGameTests runGameTestServer --console=plain` 成功（17 项 GameTest 全部通过）；`git diff --check` 通过。头盔投影透明度及不同 GUI 缩放下观感仍需游戏内验收。


### 头盔投影一致性调整

- 氧量与所有短提示（包括未装备 EPP）共用曲面文字绘制：逐字沿弧线切线旋转，使用本地化视觉顺序，过长提示适配弧宽。
- 弧线及文字两端渐隐；第一人称转头时加入最大水平 1.5、垂直 1 个 GUI 像素的阻尼滞后，整组同步运动。暂停、菜单、第三人称及突变视角重置偏移。
- 本轮 `gradlew.bat compileJava --console=plain` 通过；尚未实机验证中英文警告、不同 GUI 缩放、快速转头和暂停恢复的观感。本轮只调整客户端绘制，未改补氧或耗氧规则。


### 氧气 HUD 警告标志

- 氧量读数左侧增加曲面投影三角叹号：余量 ≤30% 为琥珀色常亮，≤15% 或未装备 EPP 为橙红色；仅橙红色每秒一次柔和明暗闪烁，暗部仍保留轮廓。
- 图标与文字共用曲面变换和整体惯性位移，不占用提示文字行。保留既有 HUD 显示条件（未装备且在安全空气中不额外唤出 HUD）。
- 待游戏内检查低氧、未装备、补氧跨越阈值，以及中英文和 GUI 缩放下的图标间距与闪烁观感。


### HUD 连续曲面网格（替代逐字旋转方案）

- 文字、警告三角和氧量条先统一绘制到透明离屏纹理，再由 64×24 细分网格投影；同一个字符和图标内部也发生连续形变，包含向右上方弯曲及边缘透视压缩。
- 纹理随 GUI 缩放以 2–6 倍分辨率复用，网格坐标预计算；采用预乘透明度混合，避免透明边缘重复乘 alpha。退出连接时释放纹理；投影后恢复 framebuffer、视口、矩阵及混合等绘制状态。
- 保留轻微转头惯性、两端渐隐、琥珀色常亮和橙红色每秒一次闪烁规则。没有更改氧气玩法或网络数据。
- 验证：`gradlew.bat compileJava test --tests "*VisorSurfaceTest" --console=plain` 通过（4 项曲面测试：锚点、字形内部非线性弯曲、全网格不折叠/翻转、渐隐范围）；差异检查通过。
- 待实机：GPU 离屏合成、文字及三角形实际形变、亮暗背景透明边缘、中英文、GUI 缩放/窗口大小变化、菜单叠加、退出重进及转头舒适度；本轮未声称完成这些视觉验收。

### 未提交曲面 HUD 收尾检查（2026-09-18）

- 修复投影合成的低透明度截断：原版 `position_tex_color` 会丢弃 alpha < 0.1 的片元，
  使 alpha=20/255 的细光晕消失，alpha=40/255 的警告暗部在两端渐隐后出现截断。
  改用已依赖的 LDLib2 2.2.36.a `gui_texture` 着色器（仅丢弃完全透明片元），
  保留预乘透明度混合；已核对本地源码与实际依赖 JAR 的着色器及顶点格式。
- 渲染状态在 `GuiGraphics.flush()` 前保存，避免将其强制开启的深度测试误当作调用前状态。
  离屏绘制明确开启 RGBA 写入并使用加法混合方程，结束后恢复原颜色写入掩码、清屏颜色、
  RGB/alpha 混合方程及既有矩阵、framebuffer、视口、裁剪和深度等状态。
- 隐藏 OpenGL 窗口在 RTX 3060 Laptop GPU 上编译并运行实际依赖 JAR 中的着色器：
  5 档透明度 × 2 档渐隐 × 黑/白背景，共 20 组像素读回结果符合预乘 alpha 合成公式；
  旧着色器在同一测试中失败 6 组，新着色器全部通过，未产生 OpenGL 错误。
  本地验证程序：`build/VisorAlphaSmoke.java`；日志：`build/visor-alpha-smoke.log`。
- `gradlew.bat build --console=plain` 成功；545 项单元测试（含 4 项曲面几何测试），
  0 失败、0 错误、0 跳过；LDLib2 基线检查和 `git diff --check` 通过。
- GPU 像素测试只验证着色器合成，不等同于 Minecraft 客户端完整验收。
  中英文字形、不同 GUI 缩放、菜单叠加、退出重进和转头观感仍需游戏内确认。
  本次只收尾现有 HUD 改动，未扩展 R6/R7；保留原有设计文档及 output/tmp，未提交、未推送。
