# 已发现问题

本文记录当前开发分支中已复现、但尚未完成修复或优化的问题。问题状态以实际运行结果为准。

## 首次打开 LDLib2 界面时短暂卡顿

**状态：已复现，StarboundMC 接入层优化已完成，冷启动待评估**

**影响范围：** 首次打开星图、传送器等 LDLib2 界面。

### 表现

进入游戏后，第一次打开任意一个 LDLib2 界面时会出现短暂卡顿。关闭后再次打开同一界面，
或先打开另一个 LDLib2 界面，卡顿通常会明显减轻。

### 复现方式

1. 启动游戏并进入世界。
2. 不打开其他 LDLib2 界面，直接打开星图或传送器。
3. 观察首次打开时的短暂停顿。
4. 关闭界面后再次打开，比较第二次打开的流畅度。

### 初步定位

共享卡顿主要来自 LDLib2 的首次渲染冷启动，而不是传送器业务逻辑或跃迁网络逻辑。首次绘制
文字和 SDF 控件时，LDLib2 可能延迟完成以下工作：

- 创建字体渲染器；
- 创建字体字形图集；
- 生成并上传首批中英文字符；
- 初始化相关的显卡纹理和渲染状态。

因此，只要星图和传送器都表现为“本次游戏会话第一个 LDLib2 界面卡顿”，就符合库级冷启动特征。

### StarboundMC 侧已完成的优化

传送器目的地列表原先会在服务器快照到达后清空并重建全部按钮、图标和文字组件，这会额外
触发组件注册、样式匹配和 Taffy 布局计算。当前实现已经改为保留式更新：

- 使用目的地 key 缓存并复用 `DestinationRow`；
- 服务器快照到达后只增删或更新实际发生变化的行；
- 选择目的地只切换选中 class，不再重建列表；
- 刷新数据时保留滚动位置和现有组件状态。

如果首次打开时客户端尚无目的地缓存，新快照仍需要创建首次出现的行，这是必要的数据构建，
不再是整表重复构建。该项优化降低了 StarboundMC 侧的附加开销，但不会消除 LDLib2 首次字体、
贴图和渲染状态初始化产生的共享冷启动成本。

### 当前判断

- **LDLib2：** 当前证据仍指向首次字体与渲染资源初始化；需要帧时间数据进一步确认具体占比；
- **StarboundMC：** 传送器整表重复构建已经消除，后续刷新只处理变更项；
- **服务端跃迁逻辑：** 与本问题无关。

### 后续处理方向

1. 比较本次游戏会话中第一个与第二个 LDLib2 界面的帧时间，区分共享冷启动和页面自身开销。
2. 评估在进入世界后的空闲时段预热字体和常用渲染资源是否值得，避免用无数据依据的预热增加
   常驻成本。
3. 获得帧时间数据后，若共享冷启动仍然明显，再向 LDLib2 上游
   反馈剩余的首次渲染性能问题。

本问题目前没有改变功能正确性，也没有修改现有 UI 行为；在完成优化并通过实机验证前，不标记为已解决。

## 当前宇宙与存档验证边界

当前 canonical 船存档严格读取 schema 3，早期内部开发 schema 不受支持。未知 datapack body ID 与 pose 原样保留并阻止缺少几何的航行；恢复相应 datapack 后才能重新解析位置。这是当前数据健壮性，不是历史迁移。

数学、encode/decode、save/load 与 GameTests 覆盖当前行为；固定视点/GPU smoke 覆盖本机画面和数值，不能替代星图人工交互、航行手感、双客户端专服和跨 GPU/shaderpack 验收。实际执行结果保存在本轮构建日志和 smoke 输出，不用历史测试数量代表当前通过情况。

## Rocky Moon 抵达未触发地表任务钩子

**状态：待修复**

**影响范围：** Rocky Moon 首次登陆任务、NOVA 地表抵达广播、任务终端进度快照和相关教程提示。

`ShipStoryService.isPlanetSurface` 当前只识别主世界、熔融、冰冻和荒芜地表，遗漏
`RockyMoonPlanet.ROCKY_MOON_LEVEL`。`Stage6TravelService` 与 `TeleporterManager` 在抵达后会调用
`ShipStoryService.onPlanetSurfaceArrival`，但 Rocky Moon 因此不会进入该分支，玩家在 Rocky Moon
着陆时不会触发地表任务完成、NOVA 抵达提示或任务进度刷新。

**复现方式：** 在包含 Rocky Moon 的当前数据驱动宇宙中，从飞船传送器或已命名传送器选择 Rocky Moon
地表并成功着陆，观察“第一次地表行动”任务和 NOVA 提示没有按其他地表同样更新。

**修复方向：** 将 `RockyMoonPlanet.ROCKY_MOON_LEVEL` 纳入统一地表判定，并补充 Rocky Moon 的
抵达、任务快照、个人提示和重启后状态回归测试；不要在任务层为 Rocky Moon 增加一套独立分支。
