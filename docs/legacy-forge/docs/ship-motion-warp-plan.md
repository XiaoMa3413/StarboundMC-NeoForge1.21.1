## 0. 方案结论(已确认)

**选定方案:虚拟移动 — 只有太空背景移动,船体方块/玩家/相机永不移动;背景随"虚拟位置 V(t) + 虚拟朝向(yaw/pitch)"锚定渲染。**

- 核心原则:船体世界锚点 `W₀=(0,102,0)` 永不变;新增"飞船虚拟位姿 `V(t), yaw(t), pitch(t)`"(纯数学,服务器权威);行星/星域按虚拟位姿旋转平移后渲染。窗外产生真实视差与真实转向扫场,零搬块、零光照、零区块成本。
- 已确认参数(2026-08-17):
  1. **停泊视角**:所有行星停泊视角一致 38.4°(停泊距离 = 1.61×半径,无视觉回归)。
  2. **跨星系总时长**:18~20s(与现状 16s 相当),超空间速度按预算自动反推。
  3. **星系内跃迁**:全程低速视差飞行 ~8s,无条纹隧道(月亮从窗外小点长满窗口)。
  4. **出发演出**:由"硬转向"改为**真实转向**——虚拟 yaw 平滑转到航向,窗外星域/行星真实扫过;行星自然后退变小 + 轻微俯仰(拉起 4°/俯冲 3°)。
  5. **燃油**:固定费(20/100)+ 超空间里程费(1 单位/800 块)。
  6. **朝向(新增)**:虚拟朝向随飞行阶段平滑变化;每颗行星有独立的停泊朝向 yaw_dock,停泊时窗外星空方位各异。

## 1. 背景与现状(已验证的事实基础)

- **船体是静态的**:船维度(世界锚点 `0,102,0`)里的固定结构——当前程序壳为 13×8×21 块的紧凑探索艇,或 `ship.nbt` 模板(原点 `0,102,0`)。
- **太空背景是"相机相对"绘制的**(`PlanetRenderer`,AFTER_SKY 阶段):行星固定相机偏移、星域固定外壳、大气辉光按角度计算;窗外景色不随任何"位置"变化。
- **跃迁是 16 秒定时演出**:转向 50t → 条纹隧道 → 到达淡入;服务器 320 tick 定时器到点直接换行星。
- **燃油**:1000 上限,20/100 固定费;持久化 `ShipStateData`(Planet/Fuel/Visited/CurrentEntry)。
- 星图 UI 有与跃迁同步的飞船动画;玩家无物理反馈。

## 2. 架构与坐标系

### 2.1 坐标与位姿状态

| 层 | 定义 | 说明 |
|---|---|---|
| 世界锚点 W₀ | `(0,102,0)`(船维度) | 船体实际所在,永不改变 |
| 虚拟位置 V(t) | `(vx,vy,vz)`,服务器权威 | "船在太空中的位置",纯数学位移 |
| 虚拟朝向 yaw(t)/pitch(t) | 度,服务器权威 | "船头指向";决定窗外背景的旋转与扫场 |
| 行星虚拟坐标 Qp | 常量表(§3) | 行星是虚拟空间中的固定点 |

### 2.2 渲染变换(唯一核心公式)

> 虚拟点 Q 的绘制偏移 = `R_yaw(−yaw(t)) · R_pitch(−pitch(t)) · (Q − V(t)) − 玩家眼位局部偏移`

- 由现状"相机相对固定偏移"改为该公式:V 移动 → 窗外天体真实位移;**yaw/pitch 变化 → 窗外天体(行星/星域/伴星)整体真实旋转扫场**(这就是"转向"的物理来源)。
- 玩家在船内走动 → 窗外微小视差(免费的真实感加成)。
- 相机本身 0 位移、0 旋转;仅加速/减速时有亚像素**纯旋转**微抖(≤0.15°,不脱位)。

### 2.3 停泊视角的定义

停泊时:V = V_dock(p),yaw = yaw_dock(p),pitch = 0。行星必出现在窗正前偏移 `O_p = D·(dp/80.5)`(D=(0.5,10,80),视角恒 38.4°):

> `Qp = V_dock(p) + R_yaw(yaw_dock(p)) · O_p`

- 玩家视角不变(行星仍在正前 38.4°),但**星域/伴星的方位随 yaw_dock(p) 旋转**——每颗行星停泊时窗外星空各不相同。
- 伴星方位同样随 yaw_dock 旋转(熔岩月在丰饶窗外的方位由 yaw_dock(丰饶) 决定)。

| 行星 | 虚拟半径 Rp | 停泊距离 dp | 停泊朝向 yaw_dock | 停泊位 V_dock | 虚拟坐标 Qp(= V_dock + R(yaw_dock)·O_p) |

| 荒芜 BARREN | 4.0 | 6.44 | 300° | (−5000, 102, −2000) | (−5005.5, 102.6, −1996.8) |

> 注:表内为 0.1 缩放后的虚拟空间坐标(`ShipSpace.SCALE` 已移除,以 `REF_VIEW_OFFSET=(0.5,10,80)` 为基准,视角 38.4°不变);yaw_dock 取值任意(决定停泊星空方位,无玩法影响,可调);Qp 在代码里由公式 `V_dock+R(yaw_dock)·O_p` 计算,表内为参考值。MOLTEN 的 210° 为防 LUSH 重叠由 120° 修正。

## 4. 飞行阶段机(服务器 `ShipFlightController`,距离 + 朝向判据,已实现简化版)

| 阶段 | 触发 | 位置/朝向 | 时长 |
|---|---|---|---|
| DOCKED | 默认 | V=V_dock, yaw=yaw_dock, pitch=0 | — |
| TURN | 跃迁开始 | V 静止, yaw: `lerp(yaw_dock→routeTangent)` s 曲线 2s | 40t (2s) |
| ACCELERATE | TURN 结束 | 沿 `FlightRoute` S 曲线前进, yaw 跟切线 | 40t |
| HYPERSPACE | 仅长程(>300) 且未到减速区 | 同上, S 曲线持续, 条纹/音效驱动 | 余量 |
| CRUISE | 仅短程 | 同 HYPERSPACE 但无条纹 | 余量 |
| DECELERATE | 距结束 80t | S 曲线减速, pitch 俯冲 −3°(s 曲线) | 40t |
| ARRIVE | 最后 40t | yaw: `lerp(routeTangent→yaw_dock)` s 曲线 | 40t |

- **时长模型(已按决策改为正比)**:`duration = 160 + (dist-300)/30`, cap 560t。短程(≤300,如 LUSH↔MOLTEN 83) 固定 160t/8s;长程如 LUSH↔FROZEN 7211 → ~390t/19.5s, LUSH↔BARREN 5385 → ~330t/16.5s, 极远 12530 → 560t/28s。旧模型 `360+(dist-300)/12000*40` 已废弃。
- **位置曲线**:`u=smoother((tick-TURN)/(total-TURN))`, `pos=route.pointAtProgress(u)` 全程单 S 曲线,起停平顺;`FlightRoute` 为切线+圆弧+径向 的防穿透几何(keep-out 1.45R,见 `ShipFlightController:92`)。
- **朝向**:已改为**切线驱动**:中段 yaw = 路线切线 `atan2(dx,dz)`;首尾 40t 内 s 曲线过渡到停泊朝向;pitch = `4*acc*(1-decel)-3*decel*(1-arr)` 峰 4° 谷 −3°。
- 超空间条纹强度/引擎音调 ∝ 实际阶段(HYPERSPACE 才显示,CRUISE 无条纹)。
- 所有朝向过渡用 s 曲线(平滑起步/收尾),理想 ≤45°/s(当前切线驱动在致密圆弧段需后续限速)。

## 5. 渲染细节(客户端)

- **星域两层**(均乘背景旋转):
  - 远壳:现有 2000 颗 @200 距离(巡航时近乎静止,超空间拖尾);
  - 近壳:新增 ~300 颗 @30–80 距离(**巡航时真实流过窗口**——现状缺失的"船在动"关键感)。
- 行星角尺寸/大气辉光壳 ∝ asin(Rp/距离),自动随距离变化;接近末段行星快速长满窗口。
- **转向扫场**:yaw 变化时行星/星域/伴星整体旋转扫过窗外(取代旧"硬转向"演出)。
- 相机微抖:纯旋转,幅度 ∝ 加速度。

## 8. 验收标准

1. 站在桥窗旁:出发时**转向扫场**——行星/星域整体扫出窗外,行星自然变小后移;恒星(近壳)真实流过;加速时微抖与引擎音升高。
2. 超空间条纹强度与实际速度一致;跨星系时长 18~20s,随距离变化。
3. 月际跃迁全程视差:熔岩月从 4.4° 长到 38.4°,无条纹。
4. 玩家在船内走动时窗外天体有微小视差。
5. 停泊视角与现状完全一致(38.4°,行星在窗正前);不同行星停泊时窗外星空方位不同。
6. 旧存档加载后停泊状态正确;跃迁中强退重进状态一致。
7. 性能与现状同级(无搬块开销)。

## 9. 实现步骤(每步可独立验收)

1. **步骤 1 — 世界锚定渲染**:`PlanetRenderer` 改 `R(−yaw)·R(−pitch)·(Q − V) − eyeLocal` 变换;行星坐标表 + yaw_dock 表;V/yaw 初始 = 停泊位姿;近星壳。验收:窗外观感与现状一致(含转向后星空方位正确)。
2. **步骤 2 — 虚拟推进 + 距离判据**:`ShipFlightController`(DEPART/APPROACH/DOCKING + 短程对称曲线 + 朝向 s 曲线过渡)+ `SyncFlightPacket` + `ShipStateData` 持久化(含 ShipYaw);先不做超空间条纹改动(长程临时简化)。验收:跃迁时长随距离变化,转向扫场成立,停泊视角不变。
3. **步骤 3 — 超空间 + 表现层**:HYPERSPACE 阶段(含航向漂移)、条纹速度驱动、引擎音调、相机微抖、星图 UI 动态进度与朝向。
4. **步骤 4 — 燃油里程费 + 性能日志 + 重启恢复打磨**。
