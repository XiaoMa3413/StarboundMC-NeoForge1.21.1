## 目标与设计边界

逐个把仍使用原版手绘或旧按钮组件的普通功能方块界面迁移到 LDLib2。普通机器不是星图：
界面应简单直接，尺寸和信息占比接近旧界面，只利用 LDLib2 精修间距、边框、焦点、悬停、
滚动、按钮状态和物品交互。

- 每个页面可有独立视觉语言，不强制沿用传送器配色或装饰。
- 共享层只提供 `ModularUI` 生命周期、布局和稳定控件，不建立统一的大型仪表盘外壳。
- 不借 UI 迁移修改服务端业务、菜单槽位语义、网络权限或注册 ID。
- 每个方块独立实现、测试、客户端验证和提交；未经确认不批量替换所有页面。
- 旧 `ship_console` 为存档兼容保留且已废弃，不纳入迁移。

## 每页质量门

1. 编译和相关单元测试通过。
2. 菜单数据、槽位索引、网络操作和服务端权限与迁移前一致。
3. GUI Scale 与常见窗口比例下不裁切、不重叠；键盘焦点和鼠标滚动正确。
4. 用户亲自完成视觉和关键交互验证；除非明确要求，不使用截图分析消耗额外验证时间。
5. 只提交项目源码和资源；`.agents/`、`LDLib2/`、临时截图及运行文件始终排除。
