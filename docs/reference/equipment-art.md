# 已确认装备美术

依据用户确认的 V01 概念及后续精修反馈制作六把武器与四套防具。最初概念身份及校验值见 `dev-assets/equipment/approved-v01.json`，制作源和可编辑模型说明见 [装备源文件](../../dev-assets/equipment/README.md)。

## 武器

| 编号 | 装备 | 主要外观 |
| --- | --- | --- |
| W01 | 钨钢军刀 | 钢灰单刃、紧凑护手、琥珀识别点 |
| W02 | 线圈手枪 | 双铜线圈、笼式方枪口、青色电量指示 |
| W03 | 耐钢战戟 | 长分段杆、宽刃和短后钩、青绿导槽 |
| W04 | 等离子卡宾枪 | 后置能量匣、枪托、短护木与青绿窗口 |
| W05 | 星核裁决刃 | 宽重刃、蓝紫导槽、根部菱形星核 |
| W06 | 星核轨道炮 | 加粗核心仓、开放双导轨与三段支架、散热鳍、电容组与缓冲后托 |

每把武器有独立 32×32 透明 GUI 像素图，第一/第三人称、掉落与展示使用实际方块模型；两侧的指示灯、能量窗口与导轨细节均保留。军刀为连续刃缘和阶梯刃尖；战戟为分段蓝杆与弧状阶梯刃缘；裁决刃为收束刃尖、银边和根部核心爪座。枪械使用实际镂空枪口、分层机匣/能量仓。原生分视角模型加载器负责切换，不以 GUI 缩略立体模型替代专用图标。基础小刀维持原有资源。

刃类使用刃面凹槽、刃脊倒角、护手连接与分段握柄；枪械使用机械接缝、检修板、护圈、散热结构和内凹发射口。轨道炮相对初版实体深度增加35%，第一人称比例由0.43增至0.51，第三人称为0.66。

三把枪的主手第三人称使用原生 CROSSBOW_HOLD 姿势，依据同步的头部角度抬臂；模型 +X 枪口轴经左右手变换朝向前方。游泳、滑翔和正在使用副手物品时让原版动作优先。客户端最终姿态钩子仅在蹲伏持枪时撤销原版追加的0.4弧度双臂偏移，保留身体降低和呼吸。持枪姿势是客户端投影，不增加网络状态或改变服务端射线。第一人称蓄力与开火回执后坐沿用原实现。

## 防具

| 编号 | 套装 | 主要外观 |
| --- | --- | --- |
| A01 | 钨钢拓荒 | 矿灯、琥珀整面罩、银边工作胸板/双工具袋、左腕终端与护膝工作靴 |
| A02 | 耐钢先锋 | 深T形面罩、厚护颈、包边厚肩甲、分体胸块/腹甲、叠层腿甲与重护胫 |
| A03 | 钛合金游骑 | 紧凑传感盔/青绿横面罩、轻肩甲、分段青绿胸甲/腹甲、窄护膝与踝稳定器 |
| A04 | 星核守望 | 紧凑银边蓝紫头盔、阶梯颊甲、包边肩甲、菱形胸核与分层髋甲/前臂甲 |

16 个部件均有 32×32 透明像素图。穿戴层是按原版骨架分件的实际 Humanoid 模型，头胸靴使用外层、护腿使用内层；原版负责对应部位显示与动作姿态复制。内衬包覆玩家皮肤的外套/裤腿层，避免关节透出原有皮肤颜色。EPP 保持独立背部装备显示。

材质分区为 256×256，原生层定义与 UV 一致；资源重载后清空模型缓存并重新烘焙。资源或几何定义损坏会明确报错，不静默套用旧式盔甲模型。

14份Blockbench工程是模型与嵌入材质的制作源。模型在真实Blockbench中编辑、原生保存/重开检查后由`equipment_models.py`导出。生成器不会重建或覆盖工程；普通导出无需运行建模工具。原生Java Codec与生产转换的几何/UV/旋转一致，武器项目锁定工具内1.9–1.21.5格式。编辑边界见[源文件说明](../../dev-assets/equipment/README.md)。

## 生成与验证

```powershell
python scripts/generate_weapon_resources.py --stage 3
python scripts/generate_armor_resources.py
& .\scripts\dev.ps1 -PweaponSmoke runClient --offline --console=plain
& .\scripts\dev.ps1 -ParmorSmoke runClient --offline --console=plain
& .\scripts\dev.ps1 -PweaponEffectsSmoke runClient --offline --console=plain
```

武器客户端夹具检查实际 GUI 精灵与非空渲染面、左右手持握、原生角色第三人称正侧视图、完整模型展示及资源重载，输出 `run-weapon-smoke/screenshots/weapons-blockbench-v03`。三把枪增加左右手±30°俯仰、蹲姿、副手盾牌场景，并由实际骨架/烘焙变换矩阵核验枪口方向。防具夹具输出 `run-armor-smoke/screenshots/armor-blockbench-v03`，包含各套正侧背、16 部件中文说明及同步属性。战斗夹具输出`run-weapon-effects-smoke/screenshots/blockbench-effects`，检查模型动作与实际攻击路径。

美术使用原有物品 ID；武器/防具数值、制造、命中、套装判定与协议仍遵循[武器](weapons.md)、[防具](armor.md)和当前架构。每轮执行结果与修复回溯见根目录 process，尚待人工长期游玩的事项见 current-work。
