# 已确认装备美术

当前游戏模型使用用户已验收的 V04 原生工程：`dev-assets/concept-rebuild-v04/`。六把武器和四套防具共10份 `.bbmodel` 是造型与嵌入纹理的权威来源；验收记录在该目录 `delivery.json`。历史 V03 工程仅供回溯。

## 武器

| 编号 | 装备 | 主要外观 |
| --- | --- | --- |
| W01 | 钨钢军刀 | 钢灰单刃、紧凑护手、琥珀识别点 |
| W02 | 线圈手枪 | 双铜线圈、笼式方枪口、青色电量指示 |
| W03 | 耐钢战戟 | 长分段杆、宽刃和短后钩、青绿导槽 |
| W04 | 等离子卡宾枪 | 后置能量匣、枪托、短护木与青绿窗口 |
| W05 | 星核裁决刃 | 宽重刃、蓝紫导槽、根部菱形星核 |
| W06 | 星核轨道炮 | 加粗核心仓、开放双导轨与三段支架、散热鳍、电容组与缓冲后托 |

每把武器有独立 32×32 透明 GUI 像素图，第一/第三人称、掉落与展示使用实际三角网格模型；两侧的指示灯、能量窗口与导轨细节均保留。军刀、战戟及裁决刃保留已验收的连续斜面和刃缘。枪械使用实际镂空枪口、分层机匣/能量仓。原生分视角模型加载器负责切换，不以 GUI 缩略立体模型替代专用图标。基础小刀维持原有资源。

武器通过 NeoForge 内置 OBJ 加载器接入，保留任意斜面及原 UV。游戏坐标中枪口为 +X，近战刃尖为 +Y；握把位置与手持变换由生产导出器适配。三枪当前实际网格尺寸相对V04接入基线为：线圈手枪85%、等离子卡宾枪150%、星核轨道炮200%。倍率围绕握把锚点应用到三轴顶点，维持握持位置；GUI独立图标不随之缩放。GUI 使用现有独立像素图，基础小刀不在本轮替换范围。

三把枪的主手第三人称使用原生 CROSSBOW_HOLD 姿势，依据同步的头部角度抬臂；模型 +X 枪口轴经左右手变换朝向前方。游泳、滑翔和正在使用副手物品时让原版动作优先。客户端最终姿态钩子仅在蹲伏持枪时撤销原版追加的0.4弧度双臂偏移，保留身体降低和呼吸。持枪姿势是客户端投影，不增加网络状态或改变服务端射线。第一人称蓄力与开火回执后坐沿用原实现。

## 防具

| 编号 | 套装 | 主要外观 |
| --- | --- | --- |
| A01 | 钨钢拓荒 | 矿灯、琥珀整面罩、银边工作胸板/双工具袋、左腕终端与护膝工作靴 |
| A02 | 耐钢先锋 | 深T形面罩、厚护颈、包边厚肩甲、分体胸块/腹甲、叠层腿甲与重护胫 |
| A03 | 钛合金游骑 | 紧凑传感盔/青绿横面罩、轻肩甲、分段青绿胸甲/腹甲、窄护膝与踝稳定器 |
| A04 | 星核守望 | 紧凑银边蓝紫头盔、阶梯颊甲、包边肩甲、菱形胸核与分层髋甲/前臂甲 |

16 个部件均有独立像素图。穿戴模型按装备槽和七个原版骨骼拆分，使用 `ModelPart.Cube` 自定义面片输出，原版继续处理姿态复制、部位显隐、幼年缩放和附魔闪光。胸甲绑定双臂、护腿绑定双腿和腰部、靴子单独绑定双腿；模型缓存按套装与装备槽区分。EPP 保持独立背部显示。

纹理使用验收工程内嵌的1536×1088投影图，保留概念原有绘制光照；不是重新绘制的PBR材质。资源重载后清除模型和几何缓存。缺失或损坏几何明确报错。

`extract_v04_meshes.py` 在真实Blockbench中读取实际渲染网格，输出带源SHA256的 `dev-assets/runtime-v04/` 三角面缓存。`equipment_mesh_export.py` 校验源哈希并导出武器OBJ/MTL及防具 `equipment/armor_meshes.json`；普通导出不需要启动Blockbench。盔甲从概念人体比例适配原版方块骨架，仅生产输出变形，验收工程保持不变。生产适配包含各套头盔包覆宽度与原版皮肤外层所需的深色内衬，防止头发、衣袖在关节处穿出。星核守望头盔使用 `dev-assets/equipment-fit/starwarden_helmet.bbmodel` 内重塑的最终尺寸网格（约10.00×9.65×10.62像素）；直接绑定头部，运行时缩放为1，不再使用整体12%放大或头盔方形补洞内衬。

## 生成与验证

```powershell
python scripts/generate_weapon_resources.py --stage 3
python scripts/generate_armor_resources.py
& .\scripts\dev.ps1 -PweaponSmoke runClient --offline --console=plain
& .\scripts\dev.ps1 -ParmorSmoke runClient --offline --console=plain
& .\scripts\dev.ps1 -PweaponEffectsSmoke runClient --offline --console=plain
```

武器客户端夹具检查实际 GUI 精灵与非空渲染面、左右手持握、原生角色第三人称正侧视图、完整模型展示及资源重载，输出 `run-weapon-smoke/screenshots/weapons-v04-game`。三把枪增加左右手±30°俯仰、蹲姿、副手盾牌场景，并由实际骨架/烘焙变换矩阵核验枪口方向。防具夹具输出 `run-armor-smoke/screenshots/armor-v04-game`，包含各套正侧背、16个部件独立穿戴、蹲姿、EPP、中文说明及同步属性。战斗夹具输出`run-weapon-effects-smoke/screenshots/blockbench-effects`，检查模型动作与实际攻击路径。

美术使用原有物品 ID；武器/防具数值、制造、命中、套装判定与协议仍遵循[武器](weapons.md)、[防具](armor.md)和当前架构。每轮执行结果与修复回溯见根目录 process，尚待人工长期游玩的事项见 current-work。
