# 制造、钱包与机器界面

服务端拥有库存、钱包与队列 authority，客户端只显示菜单数据。具体配方、产率、时长、数值与掉落表以当前代码和数据为准；未完成验收见[当前工作](../current-work.md)。

## 体素与打印

- 钱包属于玩家，余额必须有效且非负；缺失/损坏的已保存余额不解释为新钱包。
- 提炼机手动开始后连续处理单件周期。停止或取走输入取消尚未完成的周期，不消费该周期输入或产生收益；已完成的公共产物可由第一个合法领取者取得。
- 打印机只有输出槽，材料从玩家库存 reservation；有效请求在服务端预付材料和钱包费用，进入共享 FIFO 队列并保留请求者身份，不另建客户端库存。
- 请求者可取消自己尚未开工的条目并完整退款，当前执行条目不能取消。输出阻塞时暂停，避免吞产物或越过队列；拆机按当前掉落/退款实现结算，不能凭历史日志推测新规则。
- 初始船提供打印站；提炼机有当前制作/打印获取入口，基础获取链避免必须先拥有体素才能取得体素来源的循环。

## 菜单与 UI 生命周期

当前传送器、燃料、升级、存储、提炼、打印、合金炉等机器页面使用 LDLib2 与 StarboundModularScreen 生命周期桥接。原版菜单拥有真实槽位和同步；LDLib2 不维护第二套物品 authority。请求仍需服务器校验菜单、方块/距离、槽位权限和当前世界状态。

打印站遵守已确认的紧凑石墨风格，详见[制造终端风格](../ui-fabrication-style.md)与[机器 UI 合同](../ui-design-contracts/ship-machines-polish.md)。其他页面不因此被授权复制打印站结构或重新设计。

飞船 `ship_console` 的手绘 AbstractContainerScreen 仍有实际入口，其 SciFiButton 仍由当前星图使用。两套星图的共同 authority 见[导航 reference](universe.md)；是否合并界面须先确认产品用途。
