# N.O.V.A. 与飞船恢复

本文记录已实现边界，后续缺口集中在[当前工作](../current-work.md)。剧情、任务和存档 authority 见[架构](../architecture.md)，UI 视觉仍遵守[美术规范](../ui-art-direction.md)。

## 个人与共享状态

- 船体核心、亚光速引擎、燃料与航行状态是服务端共享船况；个人教程、任务和 HUD 回执属于玩家状态。客户端终端/通信只展示同步快照。
- 终端请求必须绑定当前打开且仍有效的菜单、container ID、请求身份与权限。显示动画完成不能直接替代服务器确认。
- 当前序章覆盖苏醒、Safe Mode、核心恢复、首次地表行动、物质操作器教程与矿物扫描等进度。后加入者读取当前船况，个人提示与共享修复不相互冒充。
- N.O.V.A. 广播是独立通信层，当前 HUD 规则见 [HUD reference](hud.md)。任务驱动 World AR 扩展尚未落地，不应从旧 H6 计划推断其存在。

## 通讯终端

视觉与交互遵循 [N.O.V.A. 终端设计约定](../ui-design-contracts/nova-terminal.md)。LDLib2 屏幕与视图位于 `client/shipai`。

- 顶部入口为通讯、任务、资料。通讯以分层 NOVA 投影和当前答复为主；完整对话记录按需展开，不使用聊天气泡。核心未恢复或地表任务尚未激活时停留在通讯，剧情动作仍等待服务端确认。
- 任务页使用完整内容宽度，平铺主线与探索准备，只展开一项。锁定任务可阅读前提；进行中任务提供追踪和上下文询问，维修点火中不重复提供询问。已完成任务显示待领或已领取状态，不保留追踪、询问的禁用按钮。
- 从任务询问进入通讯后，顶部显示该任务上下文，返回入口恢复同一任务与阅读位置。关闭、重开或 resize 保留当前页、筛选和阅读状态；断开连接后清空。这些只是客户端会话状态，不写入玩法存档。
- 中英文正文允许换行；宽度或高度不足时收紧留白并使用滚动。窄窗口的话题选择临时替换答复区，选完恢复完整答复，不以缩字挤入全部控件。
- 追踪、领奖励继续使用当前菜单身份与服务端任务快照。等待期间不乐观修改任务或奖励；未确认动作保留原状态并允许重试。

## 亚光速维修

- `ship_engine_unit` 是当前可交互维修单元；既有 `ship_engine` 保持推进器模型/显示职责，不能用来维修。
- 维修使用一个原版库存槽和当前点火核心。在核心在线、首次地表行动与矿物扫描完成、个人物质操作器采矿等级满足要求后，服务端接受首次有效安装并消耗一个核心，进入共享点火计时。
- 同时操作多个单元也只有第一次共享状态转换消耗核心。失败、已完成状态不额外消耗；不扫描玩家背包扣钻石。
- 关闭界面、离线或拆掉单元不取消已经开始的共享点火。未被消费的槽内物品按拆机逻辑掉落。
- 单元槽位保存在方块实体，共享维修进度保存在船况；正常保存/重启应保持两者。此模型没有承诺跨文件断电原子事务。
- 当前单元需要创造模式放置，未加入初始船模板或生存制作配方。超空间引擎只有现有状态/门禁显示，正常维修动作与获取链尚未实现。

终端再制造、设备灯光/通断电外观、完整人工序章及联机/重启矩阵均在 current-work，不继续维护旧施工计划作为并行规范。
