游戏资源 `src/main/resources/data/starboundmc/structure/starter_ship.nbt` 基于
[用户存档结构](blueprints/shuttle-interior-2026-09-05/shuttle-interior.nbt)，仅按后续要求在储物柜中加入开局补给：
**1 把求生匕首、3 罐应急食物罐头**。方块、朝向和其他方块实体数据保持一致，原始归档不修改。

- 长 33 格、翼展 23 格、高 11 格，世界范围 `(-11,100,-15)` 至 `(11,110,17)`，船头朝 +Z。
- 1,178 个非空气方块，3 个方块实体；保留用户的半砖、楼梯形状、设备位置和全部朝向。
- 主通道已由用户铺设石英半砖，不能再用最初蓝图“Y=101..103 全空气”断言覆盖这次布置。
- 保留用户删除舰门、合金炉、工作台和多余货箱后的布局；不自动补回旧设备。
- 三台发动机的朝向采用存档中的 NORTH；原始 HTML 仅作为早期构想留档。

## 实现

`ShipStructure` 从内置模板读取方块列表，以 `(-11,100,-15)` 为原点，并通过
`ShipChunkGenerator.fillFromNoise()` 放入六个新区块（X=-1、0；Z=-1、0、1）。
生成器原本产生空区块，所以只放置模板中的非空气方块，不再叠加旧的程序化船壳和家具。
旧 `StarterShipHullProfile` 几何实现及对应旧蓝图测试已移除。

方块实体 NBT 在 ProtoChunk 中保存，转为 LevelChunk 后通过原版注册表加载流程恢复。
设备和座椅共享位置常量同步到存档坐标；返回飞船使用实际传送器上方落点。
旧存档找不到新位置的传送器时仍使用原有回退落点。

可选自定义 `starboundmc:ship` 模板的既有原点约定不变，本次内置默认结构使用独立的 `starter_ship.nbt`。
内置默认结构不需要玩家另外安装数据包。
现有已生成的飞船不会自动重建，用户手工修改的验收存档和原始备份均保持不变。
