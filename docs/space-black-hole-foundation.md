# 可查询恒星背景与黑洞成像基准

背景基线：`423ae02`；定时吸积盘基线：`f8a26fa`，分支 `refactor/space-render-v2`。已实现方向背景查询、固定观察者 Schwarzschild 透镜和定时薄吸积盘研究预览。以下先保留背景基准的合同，再记录吸积盘扩展。研究预览显式启用；宇宙数据、航行、星图和天体类型均不变。

## 背景查询合同

`BackgroundStarCatalog` 的种子、方向、色温、相对通量及画质前缀不变。常规天空继续提交静态星点 VBO，望远镜继续使用已有 `StarfieldOptics`。`StellarBackground` 在需要方向查询时构建另一份索引；普通天空不生成这份目录、不上传查询纹理，也不分配新的渲染目标。

方向为单位球上的世界方向，颜色为线性 RGB，相对辐射按立体角归一化。原有像素通量使用 720p、70° 垂直视角的参考焦距 `f = 360 / tan(35°)` 转成方向通量 `flux / f²`。这是一项美术标定，不是天文观测数据或绝对物理亮度。银河、尘埃和颜色合成复用已有 shader 函数。

方向索引采用六个立方体面，每面 32×32 个单元，保存候选源的 CSR 范围。每颗星覆盖其最大过滤支撑范围内的所有单元，包含跨面边界。投影包围框之后用球面帽收紧候选；实际遍历单元中的完整列表，没有固定循环上限，也不会丢弃密集星群中的额外恒星。最大过滤标准差为 0.008 rad，核截断在 4.5 sigma；圆高斯被省略的尾部通量约为 0.004%。

窄光束按两个曲线方向导数生成切平面协方差，保留椭圆的轴和旋转。未分辨恒星的点扩散函数位于**成像平面**：每颗星的原有像素 sigma 与像素积分二阶矩一起经过光束 Jacobian 变换。它不会把普通视角的光学星点误当成具有固定角尺寸的实体恒星。CPU 的 `radiance` 方法另提供带参考角宽的圆高斯查询，供独立数值检查和方向预过滤；两种过滤合同在 GPU 夹具中分别验证。

宽光束过渡到 128×128×6 的 RGB 通量层级。各层先加总通量，再除以单元的**精确球面立体角**；每层的 RGB 总通量一致。层级打包到同一张二维纹理，跨面手动过滤，避免面边缘直接 clamp。0.005–0.008 rad 的主轴宽度连续混合两条路径。

| 数据 | 格式 / 布局 | Ultra 占用 |
| --- | --- | ---: |
| 方向单元 | RG32F，32×192，起点 / 数量 | 48 KiB |
| 候选编号 | R32F，1024 列，240,513 个有效编号 | 940 KiB |
| 恒星源 | RGBA32F，每源两个 texel，方向 / 尘埃份额 / RGB 通量 / 参考 PSF | 1008 KiB |
| 通量层级 | RGBA32F，128×1530，八层 | 3060 KiB |
| 静态黑洞偏折表 | R32F，2048×2 | 16 KiB |

查询数据合计 `5,177,344` 字节，约 4.94 MiB；黑洞查表另加 16 KiB。32,000 星的最大候选数为 242；Performance 的 2,000 星最多 27 个候选，查询数据 `3,309,568` 字节。地址以浮点数精确保存，构建时保证有效编号与范围小于 `2²⁴`。所有采样器均为 Minecraft `ShaderInstance` 支持的二维纹理，复用已有五个纹理单元的状态恢复。

资源只保留当前查询画质，切档释放旧目录与四张纹理；黑洞表独立缓存。重载和退出连接释放纹理与研究三角形，后续使用重建。所有 CPU 上传先解除 unpack PBO，清除 atlas 行长/偏移/字节交换，上传后恢复调用者状态；部分创建失败会回收已分配资源。失败的研究绘制回到已验收的天空，固定视点夹具则明确报错，不接受悄悄降级的研究截图。

## 黑洞数值参考

选择无自旋模型建立可复算的成像基准。Schwarzschild 方程及预计算光束的研究依据见 [Bruneton 2020，§3.1–3.3](https://arxiv.org/pdf/2010.08735)。本项目自行实现积分器与静态表，没有复制论文作者的 renderer，也没有增加其依赖。

以 Schwarzschild 半径 `rs = 1` 为单位，`u = 1/r`。光线在平面内满足：

```text
u'' = -u + 3u²/2
(u')² + u² - u³ = 1/b²
b = r_observer · sin(psi) / sqrt(1 - 1/r_observer)
```

`psi` 是静止观察者正交局部坐标中相对向内径向的夹角；不能直接拿坐标角代替。光子球为 `r = 1.5`，临界冲量为 `b = 3 sqrt(3) / 2`。CPU 参考支持所有 `r_observer > 1.5` 的内向/外向光线。

`SchwarzschildRay` 使用双精度 RK4、步长加倍误差估计及 Richardson 修正，精确定位逃逸、视界和近心点事件。返回捕获、逃逸或未解析状态，并报告未取模的方位角、近心距离、守恒误差和步数。恰好临界的内向光线是未解析的无限绕行，不能随意归类为普通逃逸光线。

独立基准包括临界边界、能量守恒、收紧容差的收敛、弱场 `2/b` 偏折，以及另用径向积分和近心点多项式根求出的强场结果。GPU 加速表另与高精度积分比较，避免用同一张表验证它自己。

研究预览固定观察者 `r_observer = 20`。内向逃逸分支按距离阴影边界的角差取对数采样，外向分支按角度线性采样；两个分支分别存一行。方位角保持多圈连续值，**插值之后**才用于正余弦，捕获区不与逃逸区插值。2048×2 表仅需 16 KiB，每个像素两次查表代替数百步积分。

预览用现有 HDR/Bloom 合成弯曲后的银河和原生恒星，固定镜头朝向银心；偏移镜头与小角度连续相机运动也有夹具。黑洞在这里仅改变背景成像，没有加入真实宇宙实体，也没有参与前景行星、船舱或世界深度。

## 背景基准交付时的边界与技术路线

- 宽光束使用以主轴选层的平均通量近似，极高长宽比的宽光束还没有完整 EWA 积分。粗层尘埃按亮度加权的份额估计，不等于逐源、逐波段的精确消光。
- 光束用局部线性 Jacobian 与高斯二阶矩过滤；捕获边界使用覆盖率抗锯齿。临界曲线附近跨越多像/捕获的强非线性束，仍需有限光束积分与专门的时间稳定性验证。
- 固定半径查表不支持观察者沿径向航行。当前首次启用会在渲染线程预计算/上传，固定镜头计时包含预热后采样；正式实体接入前要增加预热与半径相关表。
- 尚未实现吸积盘、引力频移、相对论 Doppler/beaming、延迟时间、Kerr 自旋或相交前景的曲线遮挡。这是光线和背景的研究基准，不能作为卡冈图雅效果已经完成的结论。

下一阶段先让同一条 geodesic 输出吸积盘交点和光传播延迟，再接入温度/发射谱、轨道速度、频移及薄盘透射。以外观和数值基准共同验收盘的直接像、背面像和高阶像。随后扩展观察者运动与宽光束过滤，最后推进 Kerr；不通过扭曲一张盘贴图来代替旋转黑洞。

实现前已补充 [卡冈图雅图片、制作取舍与验收参考](space-gargantua-reference.md)。先用带编号的诊断盘检查多重像，再分别校准物理辐射显示与电影曝光；当前 `r_s = 1` 与论文长度单位必须显式换算。电影视觉自旋、频移显示和镜头柔光不能凭印象组合，也不能被当成已实现的物理能力。

旋转黑洞及电影级抗锯齿的后续参考是 [James 等 2015，DNGR / Interstellar](https://arxiv.org/abs/1502.03808)。它强调有限椭圆光束在 Kerr 成像中的作用；本阶段只吸收成像方向，尚未移植其旋转时空求解器。

## 重现与回退

普通游戏默认关闭预览。开发 JVM 可显式设置 `-Dstarboundmc.debug.backgroundQuery=true` 或 `-Dstarboundmc.debug.schwarzschild=true`。二者都使用原生可查询背景，普通 StellarView 后端继续保留原有行为。

固定视点夹具使用 `-PspaceSmoke`，例如：

```powershell
.\gradlew.bat --gradle-user-home ../.gradle-home --offline `
  '-Dorg.gradle.java.installations.paths=D:/JAVA RE/jdk21' `
  '-Dorg.gradle.java.installations.auto-detect=false' '-Dorg.gradle.jvmargs=-Xmx1G' `
  -PspaceSmoke -PspaceSmokeQuality=ultra -PspaceSmokeLabel=sky-query-check `
  '-PspaceSmokeViews=@galaxy,@query-galaxy,@query-edge,@query-motion,@lens-galaxy,@lens-offset,@lens-motion,@lens-reload,@lens-resize,@galaxy-return' `
  -PspaceSmokeWidth=1920 -PspaceSmokeHeight=1080 runClient
```

夹具创建独立世界，隐藏窗口，保存截图、姿态、资源计数、CPU/GPU 时间与数值检查；不打开用户存档。`sky-query-checks.txt` 检查三个异常上传状态下的五张纹理完整读回、圆/椭圆/成像平面 PSF 查询、宽光束面边界、真实 GPU 偏折表与主深度/GL 状态恢复。普通 `test build` 不编入四个渲染夹具。

本阶段可整体 revert 回 `423ae02`；研究预览开关也能直接回到普通天空。最终验证结果记录在 [管线文档](space-render-pipeline.md)。

## 定时薄吸积盘扩展（2026-10-02）

本次从 `f8a26fa` 推进，把盘面相交和背景终点连接到同一条光线。`SchwarzschildPath` 是独立的双精度定时参考，沿用自适应 RK4 / Richardson 方法，同时积分正向累积的回溯坐标时间：

```text
dt/dphi = 1 / [b u² (1-u)]
position(phi) = observerRadial cos(phi) + rayTangent sin(phi)
dot(position(phi), discNormal) = 0
```

长度单位为 `r_s`，时间单位为 `r_s/c`；`t` 是 Schwarzschild 坐标时间，不能解释为盘上粒子的固有时间。有限轨迹止于 `r = 1.05` 或 `r = 64`，避免视界和无穷远的坐标时间发散。`SchwarzschildRay` 继续提供无穷远的背景方向与捕获分类。盘交点在有限轨迹上按相位递增求取，包含最终捕获光线在视界外遇到的发射物；不会先把整条捕获光线涂黑。

研究盘的内外径为 `4.63 / 9.35 r_s`，显式换算自 DNGR 参考的 `9.26 / 18.70 GM/c²`。它位于 Schwarzschild 的稳定圆轨道区之外，并非据此声称已实现电影的 Kerr 时空。诊断模式使用 6 个径向带 × 12 个方位色块，检查直接像、上下折返像、高阶像和最近交点的遮挡顺序。

`SchwarzschildDiscTable` 将捕获、内向逃逸、外向逃逸三条角度分支分开。前两者在临界角附近取对数采样；每列保存终点、无穷远相位、冲量和 129 个有限轨迹样本。GPU 对每个邻列按其各自的终点归一化，再用 Hermite 插值重建 `u / u' / t`，随后按角度混合。已终止的邻列不会与有效交点混合。1024×391 RGBA32F 合并表为 **6,406,144 字节（约 6.11 MiB）**；最后一行保存 256 个相对可见光黑体谱样本，复用第五个 sampler，不增加纹理单元或场景目标。Ultra 背景与该表合计约 **11.05 MiB**，盘预览不另分配原有的 16 KiB 偏折表。

圆轨道发射体的速度、角速度和静止观察者测得的频率比为：

```text
v = 1 / sqrt(2r-2)
Omega = 1 / sqrt(2r³)
g = sqrt[(1-1/r)/(1-1/r_observer)] · sqrt(1-v²) / (1-v mu)
```

`mu` 是发射体局部轨道速度与源到观察者光子方向的夹角余弦，来自同一条曲线光线的角动量方向。物理频移显示遵循 `I_nu,obs = g³ I_nu,emit(nu/g)`；对黑体直接查询 `T_obs = g T_emit`，保留谱强度，避免再次乘 `g⁴` 而重复计入增亮。电影显示省略该频移，保留相同的光线与盘几何。二者都复用既有 HDR / Bloom / tone mapping；当前没有加入 DNGR 的独立镜头 veiling flare。

发射温度暂定 4500 K，曝光、密度、掠射光程上限和程序纹理属于美术近似。盘光按由近到远的 `radiance += transmission * alpha * source` 与 `transmission *= 1-alpha` 合成。密度沿盘面方位剪切，材质在 `t_observer - delay` 处取样；周期坐标避免极角接缝，像素导数抑制未解析的纹理频率。程序细丝不代表流体或磁流体计算，薄层透射也不代表完整体积辐射传输。

### 当前可验证范围与限制

- 实际 GPU 检查覆盖整张表读回、定时轨迹、光谱、频移、最近盘面像及捕获前发射；CPU 另用径向积分检查时间与相位，不用查表验证查表。
- 固定观察者仍是 `r = 20`。临界角差截到 `1e-6 rad`，shader 最多处理 6 个平面交点；尚不解析无限高阶像或精确有限椭圆束跨临界曲线的积分。
- 像素导数过滤与连续相机截图用于检查当前近似，不能据此宣称完成所有速度、倾角、分辨率或其他 GPU 的时间稳定性验收。极薄高阶像仍有可见颗粒，需后续光束积分与光学过滤。
- 无限薄盘中恰好共面的光线没有孤立交点，当前明确不发射；掠射用有限光程闭合。盘厚度、自遮挡、吸收谱和散射仍待实现。
- 首次预览与资源重载仍在渲染线程生成/上传表，有预热停顿；计时取预热后的 pass，不包含这项一次性成本。退出研究预览或断开连接释放盘表、目录和纹理，普通天空没有这部分 CPU/GPU 数据。
- 尚无 Kerr 自旋、运动观察者、正式宇宙黑洞实体或弯曲前景遮挡。本阶段是可复算的薄盘成像检查点，距卡冈图雅最终视觉仍有工作。

## 视频参考后的近景与热结构（2026-10-02）

基线为首个薄盘检查点 `e5df0b9`。上节描述该历史版本；本轮增加下列能力，仍默认关闭研究预览。

盘材质由固定 4500 K 改为径向基础 `4600 (4.63/r)^0.45 K` 加局部起伏，限制在 2500–5700 K。周期方位坐标、多尺度程序密度和轨道剪切保留；两种显示共用这一发射温度，物理显示另取 `g T`。温度、密度与曝光来自视频美术对照，不是对吸积流体状态的物理拟合。暖白高光和较冷暗缝有所区分，但截图仍有明显完整环带，尚需进一步打散。

独立静止观察位置扩展为 `20 / 12 / 6 r_s`。每次半径变化释放旧表，生成并上传该半径的新表，只保留一份约 6.11 MiB 的盘表。频移测量使用各观察位置的 lapse。这里没有运动观察者的速度 / 像差，也没有连续径向运动；首次生成和切换半径仍会阻塞渲染线程。

近景 GPU 检查揭示单精度阴影角舍入在临界对数映射中被放大。新增阴影角高 / 低部分，先减高部分，再减 residual，避免先相加把低位重新舍去。保留原有 `.005 r_s / .015 r_s/c` 误差要求，没有放宽检查。实际 `12 / 6 r_s` 的 330 个定时查询最大误差约为 `.0020713 r_s / .0041437 r_s/c`。

研究盘的 High / Ultra Bloom 扩展至 5 / 7 层，并使用更宽的上采样响应；Ultra 额外两层合计不到 5 KiB（1080p）。Performance、Balanced、Custom 和普通天空保留原金字塔。`@disc-clean` 用原响应作配对检查。这是镜头柔光美术近似，不等于 DNGR 的完整 PSF / veiling flare；没有增加 sampler 或另建场景目标。

夹具新增 `@disc-near`、`@disc-close`、`@disc-clean`、`@disc-animation`、`@disc-balanced`、`@disc-high`。连续镜头和材质动画各记录 12 张 PNG 与实际渲染时间 / 姿态；写 PNG 会阻塞客户端，不能当作恒定时间步动画验收。其余资源重载、缩放、望远镜、状态与主世界深度合同保持不变。

## 有限寿命的盘材质结构（2026-10-02）

以静止近景检查点 `7b30a5b` 为回退点，继续处理视频对照中的规则环带。单一初始纹理按 `Omega(r) t` 永远剪切，会逐渐变成完整的细环。本轮改为两组有限寿命的程序结构，在发射时间处分别求局部年龄和轨道位移，周期仍使用 cos / sin 坐标；生命周期暂定 `70 r_s/c`，两组相差半周期，权重为 `sin²(pi age/lifetime)`。每组更换 seed 时权重与时间导数均为零。

每组分别求域变形、细丝、密度、温度、opacity 与发射谱，再混合其已乘覆盖率的线性辐射和 alpha。避免先平均温度 / 噪声再应用非线性辐射，导致纹理换代时整体变暗。热结构改为 `4700 (4.63/r)^0.35 K` 加密度 / 大尺度起伏，限制在 2400–5900 K；密度控制光学深度，热源函数不再额外乘一次密度。曝光系数 5、生命周期、温度相关性和随机结构均属美术参数，不是流体 / 磁流体解。

Performance 保留大尺度与较粗细丝，最细结构取均值，不执行额外的域变形 / 高频噪声；其余档保留完整材质。没有增加纹理、sampler、依赖或目标。材质空间过滤仍是程序噪声的导数近似，尚未精确积分非线性密度 / 光谱的像素平均；不能据此宣称临界有限束能量与动画稳定性已经完成。

RGBA32F 材质夹具在正 / 负发射时间检查两组 seed 换代边界，并检查 `-pi / pi` 接缝、非负辐射与 `[0,1]` 覆盖。它检查局部辐射连续性，独立轨迹与最近像基准继续检查几何；画面质量仍以远近景、两种显示和运动截图判断。临界颗粒、完整有限光束、连续观察者、盘厚度和 Kerr 继续保留为后续工作。

## 临界盘像的像素内积分（2026-10-02）

以 `13feb1e` 为回退点。用户将最高画质预算明确为本机 1920×1080 至少 50 FPS；当前优先使用新增预算改善细像采样，完整客户端基准与重现条件见 [管线验证](space-render-pipeline.md)。不以局部 GPU pass 时间替代客户端帧率。

盘材质改用同一八角点 value noise 的解析梯度。半径、周期极角和延迟时间的像素变化量先显式传入材质，再通过轨道速度、周期坐标与两级域变形的链式法则传播。噪声过滤宽度仍视为局部常量，属于一阶足迹近似。基础盘的几何导数继续在一致控制流求值，材质没有隐式导数，因而可以跳过没有发射支持的交点。程序噪声本身的值保持一致；GPU 夹具另用旧噪声函数的中心差分校验解析梯度。

临界角距在半个 `fwidth(angle)` 内使用完整像素内积分，至一个半宽度平滑过渡回基础采样。Ultra / High（含 Custom）/ Balanced / Performance 分别采用 `8×8 / 4×4 / 2×2 / 1` 条主光线。每条光线独立查同一轨迹表、求最多六个有序交点、回溯发射时间并积累辐射与剩余透射率；额外两个邻近轨迹求子像素材质足迹。轨迹终止后退出交点循环，半径在最大边缘覆盖范围之外时跳过邻近轨迹查询。等权平均的是线性辐射与透射率，发生在曝光、Bloom 与显示变换之前。没有新表、sampler、目标或第三方依赖；`@disc-single` 保留基础采样作为配对截图。

4×4 的初版在独立密集 CPU 平面交点对照中发现漏采高阶细像，单通道偏差达到约 .151，未作为通过版本。提高采样后继续检查窄像、部分覆盖与非正方形足迹，并记录密集参考与分级采样误差。该检查使用高对比、完全不透明的诊断盘，不是程序热材质或整幅背景的精确能量证明。

最终 GPU 夹具覆盖临界角两侧的八组矩形光束，以独立高精度 CPU 轨迹和首个实际盘交点构成 `128×128` 参考；包含五组可见像与三组部分覆盖。RGBA 绝对误差最大为 `.0827962`，均方根为 `.0348372`，同一参考下 4×4 的均方根为 `.0620229`；CPU 的 `64×64 → 128×128` 最大差为 `.0173951`。要求 GPU 单通道误差低于 `.1`，密集参考差低于 `.025`，8×8 总误差小于 4×4，且值有限、非负，透射率与诊断辐射在 `[0,1]` 内。较粗的 32×32 参考在收敛检查中未通过，改为更密参考，没有放宽既有轨迹、谱或连续性阈值。这些是八个诊断足迹的结果，不能推广为任意镜头的全局误差上限。

此次积分只覆盖临界区的盘发射与盘透射率。背景仍使用中心光线加现有局部 Jacobian / PSF 近似，尚未联合积分每条子光线的背景与对应透射率。表的 `1e-6` 临界角截断、六次交点上限、薄盘径向边缘覆盖与一阶材质过滤也保留；有限采样仍可能遗漏更窄像，不能称为完整有限光束或无闪烁成像。盘面同心条纹、连续运动观察者、盘厚度与 Kerr 仍需推进。
