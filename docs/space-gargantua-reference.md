## 已核实的制作取舍

以下结论来自 [DNGR 论文 §4、Fig.13–16](https://arxiv.org/pdf/1502.03808#page=24)：上下弧是同一赤道薄盘的多重像；电影视觉自旋采用 `a/M = 0.6`，与剧情要求的近极限自旋分开。Fig.15a 未应用频移造成的色彩、亮度变化，Fig.16 再加入 IMAX 的 veiling flare。该盘是艺术建模的低活跃、约 4500 K 薄盘，不能当成所有黑洞的通用模板。

[DNEG 的视角说明](https://www.dneg.com/news/new-black-hole-imagery)提醒我们，横穿暗区的盘带与观察方向有关。项目必须检验不同倾角，不能让标志性轮廓在每个方向都保持不变。

## 项目的美术判断

以下是直接查看上述剧照和对照图后形成的项目判断，不是原作者给出的数值规格。

- 冲击力来自近乎侧视的长盘带、包围中央暗区的弧像和巨大的角尺度。先做可信的空间结构，再校准高光。
- 主体颜色应从暖白到淡金过渡，强曝光区域允许接近白色；暗部仍需要细密、有方向的纹理。不能用高饱和橙色噪声代替盘材质。
- 盘内细带应有不同宽度、密度和亮度，外缘逐渐稀疏；避免等距同心线、均匀光圈和锐利贴纸边缘。
- 图中的柔光很强，甚至会抬高中央暗区的显示黑位。因此要分别看无光晕的线性图和最终镜头图：前者保证捕获/遮挡正确，后者保留清晰的主体辨识度。
- 银河和星点提供背景尺度，接近强发光盘时可以受到曝光与光学散射影响。不能为了处处可见，把背景亮度独立拉到与盘相当。
- 星光、盘像和镜头光晕需要不同的过滤。高阶像的细环由成像产生，镜头柔光由 HDR 响应产生；两者分别开关、分别检查。
- 纹理运动应连续、有径向剪切和局部差异；这是后续材质设计要求，尚未实现，也未通过电影视频对照验收。

## 实现顺序与接口约束

继续保留 Schwarzschild 双精度参考与已验收的查询背景，把吸积盘作为下一步独立交付。参考材料完善了验收标准，不要求现在放弃数值基准或一次性完成 Kerr。

1. **成像诊断盘。** 给同一条曲线光线增加有序盘面交点、穿越方向、路径延迟和终点类别。先使用带编号的径向/方位色块，分别显示直接像、背面像与绕行像；捕获光线在到达视界前仍可能遇到发光盘，不能先把全部捕获方向涂黑。
2. **发射与透射。** 定义盘的局部温度、发射谱、光学厚度和轨道运动，再处理频移与沿路径的透射。有限透明盘要按交点顺序合成；同一片盘纹理在不同像中保持身份一致。
3. **时间与材质。** 固定时间可回放；相同纹理按各自延迟后的发射时刻采样。径向剪切、细带和稀疏结构在盘坐标中生成，过滤足迹随成像变化，避免屏幕空间噪声随镜头游动。
4. **电影观感。** 共用几何与交点数据，保留完整频移的物理诊断显示，再增加明确标记的电影显示策略。曝光、色彩和光学柔光独立校准；艺术调整不得修改 geodesic、捕获分类或游戏时间。
5. **Kerr 与移动观察者。** Schwarzschild 通过之后，再验证旋转时空、局部观察者坐标及运动。`a*=0` 必须回到无自旋基准；电影参考与高自旋诊断使用各自明确的参数，不能用画圆的遮罩代替自旋求解。

论文以几何单位的 `M` 表示长度 `r_g = G M_phys / c²`，当前实现采用 `r_s = 2r_g = 1`。引用其图注参数时必须转换单位，并记录相机半径、倾角、盘内外半径、自旋和显示策略；参数不一致时不进行逐像素误差比较。

以上是项目下一阶段的设计，不代表这些能力已存在。实时加速先依据双精度参考选择查表内容和误差预算；不因离线电影方法有效，就直接引入大型离线渲染依赖或逐像素无界积分。

## 共同验收

| 场景 | 应观察的结果 | 必须保留的证据 |
| --- | --- | --- |
| 近侧视、无 Bloom 的编号盘 | 不同像指向同一盘坐标；交点次序和捕获边界正确 | CPU 参考、GPU 误差、带交点编号的固定截图 |
| 同一镜头的电影显示与物理诊断 | 几何一致，差异来自明确的辐射/显示选项 | 相同参数、相同时间的配对截图 |
| 正面、中间倾角、接近盘面 | 盘带与上下弧随视角连续变化 | 连续相机记录与固定倾角截图 |
| 远景、近景与望远镜 | 细像按像素足迹过滤，强高光仍有结构 | 720p / 1080p、多个亚像素偏移与缩放记录 |
| 缓慢移动镜头、静止及运动盘 | 像不跳变，纹理身份和延迟时间连续 | 固定帧时间的图像序列；单张截图不算时间稳定验收 |
| 质量切换、窗口缩放、双重载、退出重进 | 有界分配与采样；恢复现有状态和世界深度 | 资源计数、GPU/状态检查、完成标记 |

沿用当前 Performance / Balanced / High / Ultra、可选 StellarView 与 Direct 回退矩阵。报告同硬件、同分辨率、同视点的新增 GPU 成本与 P50/P95；当前研究预览的毫秒记录只作基线，不作为尚未实现的吸积盘预算承诺。
