# 太空渲染技术路线与执行记录

> 负责分支：`refactor/space-render-v2`。2026-09-30 接手基线：`2ff090d`。
>
> 本路线取代旧 PR 顺序，授权范围来自用户对渲染技术规划、重构与实现的完整委托。玩法与航行变更需有单独理由。

## 目标与美术方向

建立一眼惊艳、具有可信尺度和电影感的太空。深空接近黑色，银河和尘带提供层次；行星靠形状、材质和光照形成差异；恒星、逆光大气和熔岩承担高亮。保留强烈的视觉冲击力，以一致的光照和材质避免科幻概念画般的全屏彩雾与平均发光。具体判断见 [美术方向](space-render-art-direction.md)；航行阶段保持已有节奏。

未来黑洞以《星际穿越》卡冈图雅为视觉目标：弯曲吸积盘的多重像、光子环、背景透镜、时序稳定与受控高动态亮度。电影级参考不能替代实时性能与兼容性验收。

已补充 [卡冈图雅图片与制作参考](space-gargantua-reference.md)，明确源图、电影取舍和后续验收；空间几何、物理辐射与电影镜头响应分别验证。

## 审查结论

现有数据驱动宇宙、相对坐标、帧状态、静态行星网格与可选模组边界有保留价值。核心限制是局部天空投影与手工遮挡、LDR 材质和亮边式大气、圆盘恒星以及没有完整的太空回放/计时工具。详细证据见 [架构审查](space-render-architecture-proposal.md)。

明确采用分阶段替换，阶段均保持可运行与降级入口。基础状态、距离和颜色约定优先于复杂视觉效果。

## 黑洞需要的基础合同

- 背景可按世界观察方向采样，不能只提供已经扭曲后的单张屏幕图像。
- 天体距离具有明确编码，可判断近景物体与透镜区域的前后关系。
- 颜色在 HDR 空间组合，吸积盘亮度、色温、Doppler 效应与色调映射各自可控。
- 后处理拥有独立读写目标、屏幕范围和质量预算；支持较低分辨率与保持边缘的重建。
- 有固定视点、固定时间、参考图和误差比较工具，避免光子环和背景星点在运动中闪烁。

研发时先以 Schwarzschild 模型验证采样和成像，保留准确数值参考；Kerr 自旋及其加速方案随后单独选型。不能用简单屏幕径向扭曲冒充相对论透镜，也不能把非旋转模型直接当作卡冈图雅物理模型。

参考 [James 等人的 Interstellar 成像论文](https://arxiv.org/abs/1502.03808) 与 [Bruneton 的实时非旋转黑洞方法](https://arxiv.org/abs/2010.08735)。后者使用预计算曲线光束表，适合作为实时加速方向的参考；尚未决定移植其代码。

## 执行与验证规则

- 主项目在本工作树推进；用户已授权 StellarView 个性化源码改动，其独立工作树使用新分支，避免影响其他工作树。
- 每阶段记录编译、测试、截图、已知限制与回退方法；大型迁移保留明确开发切换。
- 测量 CPU 与 GPU 时避免同步等待；报告硬件、分辨率、样本数与 P50/P95。
- 视觉夹具使用独立运行目录和新存档，不打开用户现有世界。
- 保持 Minecraft 1.21.1 / NeoForge 21.1.248 的现有注册/API 路径，不添加大型渲染依赖。
- 完成状态只根据已执行检查填写；计划与静态审查不等于客户端验收。

### 电影感与晨昏线修正（2026-10-01）

用户纠正了华丽但失真的星空/行星与大气亮暗交界，并明确要求保留「一眼惊艳」的冲击力。本轮从 `5116f07` 检查点推进，不以整体降低亮度代替美术改进。

- 原生与定制 StellarView 的星点恢复暗星占多数、少量高亮星的层次；HDR 星点采用连续光学轮廓。银河改为细粒度恒星与尘带结构，普通太空关闭闪烁。
- 重写大气的采样与能量积分，地表、云和散射共享太阳透射与辐射强度；太阳在地平线处连续显露。薄大气与真实暗半球提供体积，逆光边缘保留强度。
- 太阳光学深度表由所有行星共享，GPU 占用 256 KiB；保留极薄自定义大气的数值积分。Performance / Balanced / High / Ultra 的观察采样为 12 / 16 / 20 / 28 步，各档通过掠射晨昏线的 GPU 收敛检查。
- 最终五组客户端矩阵生成 58 张实际截图：HDR2 Ultra 23、原生 High 19、Performance 7、旧版 StellarView Balanced 5、Direct + Legacy 4。缩放、资源重载、深度/状态恢复和四种 StellarView shader 检查通过；Direct 路径按设计跳过独立管线 GPU 深度检查。
- 普通生产 `test build` 成功：149 套件、725 项测试，零失败/错误/跳过；JAR 含新 shader、光学深度实现及星型资源，不含三个渲染夹具。StellarView 新提交 `f55e85f` 已构建并安装到本地 Maven，完整补丁通过反向应用检查。

本轮客户端测量受同时运行的其他 GPU 程序和功耗状态影响，不与上一检查点的毫秒记录作性能比较。下一阶段优先完善云体积、海面与近景资产、透明交叠和环食影；当前单次散射与程序星场不等于完整写实摄影模型，黑洞仍按专项路线推进。

### 原生星场主导与可选后端解耦（2026-10-01）

用户确认采用原生主导路线，以摄影和电影观感为标准继续开发，StellarView 保留为可选兼容后端。迁移基线为 `9034d46`；它及此前主项目检查点已推送 GitHub。历史段落的「尚未推送」仅描述当时状态。

本阶段重写原生目录的相对星等与连续色温，改为浮点总通量和解析像素积分星点；银河与远方星点共享尘埃透射，高画质主要增加暗星。原生星场成为所有预设的默认选项，后端选择与画质分开，Performance 始终保持原生。保持静态 VBO、既有 2,000–32,000 星预算、局部 HDR/Bloom、资源生命周期和完整回退。

主项目及夹具移除 StellarView 编译依赖，运行时通过缓存的公开 API 签名连接旧显示颜色 API 与 HDR2 API。普通克隆不需要未发布的定制 JAR；仅显式 `-PwithStellarView` 开发运行使用它。本阶段不修改 StellarView fork，也不继续扩大其源码定制范围。

已具备的后续基础是带角足迹的方向银河辐射、共用尘埃透射和可重用的星点光学积分。32,000 星目录仍通过常规投影提交，尚不能供曲线光线任意查询；方向索引或预过滤的 HDR 恒星环境、弯曲光束足迹、黑洞数值参考与吸积盘仍需后续专项实现。不能把这一阶段称为黑洞渲染完成。

下一阶段先完善完整相机运动中的时间稳定性、透明天体交叠与环的食影，再推进黑洞背景采样和数值原型。每阶段沿用独立测试世界、固定视点、GPU 数值检查和可回退提交；当前验收结果持续记录于 [管线文档](space-render-pipeline.md)。
### 星环逆光与透明层顺序（2026-10-02）

从 `607a44b` 检查点推进，完成星环太阳光照、斜角透射、行星投影与环向地表/云/大气的投影。现有环资产按冰质反照率校准并过滤细带，不新增大型依赖或 GPU 目标，也不修改共享环几何、宇宙数据、航行或星图。

HDR 局部组合改为按解析视线分段：远环、远大气、云背面、中间大气、云正面、近大气、近环。不同天体采用含包围半径的距离乘积排序，保留原选择/LOD 规则。它覆盖不相交的包围体；自定义跨天体相交体积尚不属于通用 OIT。厚云与真实多次散射仍需后续实现。

最终验证包括 30 次固定镜头捕获、真实 GPU 阴影/透射/分段能量/交叠排序与状态恢复、StellarView 四 shader、Direct 回退及 734 项生产测试。测量、目录与近似边界记录于 [管线文档](space-render-pipeline.md)。本阶段采用独立提交，可单独 revert；`607a44b` 是修改前的完整分支检查点。

接下来优先建立可按任意方向与角足迹查询的恒星背景，再用 Schwarzschild 数值参考验证曲线光线和吸积盘成像；Kerr 与卡冈图雅风格在该基准之后推进。当前星目录仍不是曲线光线查询结构，此阶段不包含黑洞渲染。

### 可查询背景与 Schwarzschild 基准（2026-10-02）

从已推送的 `423ae02` 推进。原生恒星目录新增按方向查询的 CSR 索引和保持球面 RGB 通量的层级；窄束保留椭圆足迹，宽束使用预过滤近似。常规天空继续使用原 VBO，不增加查询分配或改变其画面。研究路径按需使用约 4.94 MiB 的 Ultra 查询数据，复用当前 HDR 合成与五个纹理单元合同。

新增独立双精度 Schwarzschild geodesic、守恒/捕获/近心点/强弱场数值参考，以及固定观察者半径的 16 KiB 偏折表。光学 PSF 保留在成像平面，避免把未分辨星点的显示宽度当成实体角尺寸。显式启用的研究预览已能呈现银河透镜和多重像，没有加入宇宙实体或替换默认天空。

四条最终客户端路径及连续双重载复核完成 43 次捕获，涵盖普通画面、镜头移动、画质切换、缩放、重载、StellarView 四 shader 与 Direct 回退；查询上传/真实 GPU 数值/世界深度/状态恢复通过。普通生产构建通过 747 项测试，生产 JAR 排除四个渲染夹具。完整结果见 [管线文档](space-render-pipeline.md)，技术合同与近似边界见 [黑洞成像基准](space-black-hole-foundation.md)。

下一阶段实现同一条曲线光线上的吸积盘交点、延迟时间与辐射传输，再扩展观察者运动和宽束精确过滤，最后进入 Kerr。当前预览没有吸积盘、频移或旋转时空，尚不代表卡冈图雅视觉目标已经完成。
