# 星图重绘需求与 LDLib2 实现方案

本文是 `codex/starmap-redraw` 分支的需求基线。该分支从远端 `main` 创建，
不继承旧星图 UI 的实现；现有星球缩略图资源可以复用。

## 1. 产品目标

新 UI 由一个新的星图方块打开。首屏第一视觉信号必须是星空和星图本体，
而不是侧边栏、底部信息栏或多层卡片。界面只保留必要的边缘装饰、层级提示和
选中后的悬浮信息板。

旧的 `ShipConsoleScreen`、旧星图布局、旧按钮和旧详情组件不作为新 UI 的依赖。
跃迁业务仍由现有服务端逻辑负责，UI 不创建第二套航行状态。

## 2. 星图层级

### 2.1 深空星域

- 每颗恒星代表一个恒星系。
- 恒星系之间用虚线超空间航道连接。
- 选中恒星后显示恒星信息板，包括名称、类型、描述和该恒星系的天体数量。
- 执行“进入恒星系”后进入对应的恒星系视图。
- 深空星域右键不关闭界面；`Esc` 关闭星图。

### 2.2 恒星系

- 中央显示恒星，周围绘制行星轨道和行星。
- 行星沿轨道公转。
- 卫星以跟随行星的小点显示，并随所属行星移动。
- 卫星在该层级不可独立选择；点击卫星区域等同于选择所属行星。
- 选中行星后进入对应的行星系统视图。

### 2.3 行星系统

- 中央显示行星本体，周围绘制卫星轨道。
- 卫星沿轨道围绕行星公转，并拥有独立的选择区域。
- 选中行星或卫星后，可以在信息板中执行跃迁。
- 行星系统右键返回恒星系，恒星系右键返回深空星域。

## 3. 选中与信息板

- 单击先选择目标，不直接执行跃迁。
- 选中目标显示高亮、轨道强调和悬浮信息板；点击空白区域取消选择。
- 信息板包含：名称、类型、描述、威胁等级、矿物分布（后续数据接入）和跃迁按钮。
- 信息板根据目标位置自动避让，不遮挡目标、轨道和主要航道；靠近边缘时翻转到可用空间。
- 恒星信息板在深空星域额外显示所属恒星系的天体数量。
- 卫星的视觉点可以很小，但命中区域必须扩大；恒星系层级的卫星命中统一归属父行星。

## 4. 人体工程学与输入

- 左键：选择目标、点击信息板操作。
- 右键：返回上一级；深空星域不执行关闭操作。
- `Esc`：关闭星图；当存在可返回层级时仍优先由右键完成返回。
- 鼠标滚轮：有限缩放；拖拽：平移；提供重置视野和聚焦当前目标的入口。
- 右键返回提示通过层级标记 tooltip 呈现，例如“右键返回恒星系”。
- 不可用目标必须同时使用文字和视觉状态说明原因（当前目标、燃料不足、不可达、跃迁中）。
- 动画不能改变命中逻辑；目标在公转时，命中区域和信息板位置实时跟随。

## 5. LDLib2 方案映射

| 需求 | LDLib2 方案 | 项目自定义部分 |
| --- | --- | --- |
| 根 UI 与层级切换 | `ModularUI` + 一个根 `UIElement` | `StarmapLevel` 状态机和返回规则 |
| 星空、轨道、航道、星体绘制 | 自定义 `UIElement.drawBackgroundAdditional(GUIContext)`，使用 `GuiGraphics` | `StarmapSceneElement` 的三层绘制器和等比投影 |
| 页面布局 | Taffy layout DSL：`flex`、`gap`、`padding`、`aspectRatio` | 仅保留画布、边缘装饰、动态信息板，不建立固定侧栏/底栏 |
| LSS 主题 | `StylesheetManager` 加载资源包 `.lss` | 透明叠层、边缘装饰、选中/警告/可跃迁状态 |
| 右键返回 | `UIEvents.MOUSE_DOWN`，判断 `event.button == GLFW.GLFW_MOUSE_BUTTON_RIGHT` | 根 UI 处理 `popLevel()`；深空星域忽略右键 |
| Esc 关闭 | 屏幕 `keyPressed` 或根元素 `UIEvents.KEY_DOWN` | 无上级时关闭 `Screen` |
| Tooltip 提示 | `UIEvents.HOVER_TOOLTIPS` + `HoverTooltips` | 层级标记和返回提示文案 |
| 悬浮信息板 | 普通 `UIElement`/`TextElement`/`Button`，动态设置布局位置 | 锚点避让、目标跟随和信息字段 |
| 公转动画 | `UIEvents.TICK` 更新逻辑相位；`GUIContext.partialTick` 做帧间插值 | 行星/卫星层级轨道模型、速度、初始相位 |
| 动画过渡 | `UIElement.animation()` / `StyleAnimation` | 信息板出现、目标高亮和页面切换的短过渡 |
| 资源缩略图 | 复用现有星球缩略图 ResourceLocation | 新绘制器负责尺寸、裁切和选中状态，不复用旧 Screen |

## 6. 推荐组件结构

```text
StarmapBlock
  -> StarmapBlockEntity/菜单入口（只负责打开界面）
  -> StarmapScreen
      -> ModularUI
          -> StarmapRoot
              -> StarmapSceneElement
              -> StarmapEdgeChrome
              -> StarmapLevelMarker
              -> StarmapFloatingInfo (按需创建/定位)
```

`StarmapSceneElement` 是唯一的星图绘制与命中入口。它根据当前层级选择数据集：

- `GALAXY`: 恒星节点 + 超空间航道。
- `SYSTEM`: 恒星 + 行星轨道 + 行星节点 + 跟随行星的卫星点。
- `PLANET`: 行星 + 卫星轨道 + 可选卫星节点。

## 7. 公转模型

- 逻辑位置由 `center + rotate(orbitRadius, phase)` 计算。
- 卫星位置使用父星体的实时位置作为轨道中心。
- 相位由页面打开时的固定数据相位和客户端时钟共同决定，避免每次打开完全随机。
- 使用 `GUIContext.partialTick` 插值绘制，避免 20 TPS 更新造成跳动。
- 公转只改变客户端显示位置；服务端目标、维度和跃迁校验仍使用实体定义数据。

## 8. 开发分阶段

1. 新方块、菜单入口和空白 LDLib2 根 UI。
2. 深空星域绘制、恒星节点和虚线航道。
3. 恒星系绘制、行星轨道、公转和卫星跟随点。
4. 行星系统绘制、卫星独立命中和公转。
5. 悬浮信息板、右键返回、Esc 关闭和 tooltip 提示。
6. 复用星球缩略图，完成选中态和信息字段。
7. 接入现有跃迁请求，验证服务端权威状态。
8. 做宽屏、窄屏、GUI Scale、密集卫星和边缘目标的视觉核验。

## 9. 验收标准

- 首屏无固定侧边栏和底部信息栏，星图主体占据主要区域。
- 三个层级均可进入、返回，右键和 `Esc` 行为符合定义。
- 恒星系层级无法独立选择卫星；行星系统层级可以独立选择卫星。
- 行星、卫星公转连续，卫星始终跟随父行星，命中区域同步移动。
- 信息板不会遮挡目标，包含描述和对应层级的天体数量信息。
- 轨道、航道和星体在不同窗口比例下不拉伸错位。
- 跃迁按钮仍调用现有服务端权威请求，UI 不绕过服务端校验。
