# N.O.V.A. 舰桥通讯终端 — 设计约定

状态：2026-10-13，用户认可交互概念稿并批准实现。此文保存已确认的视觉与交互约定，当前行为见 [N.O.V.A. reference](../reference/nova.md)。

## SCREEN / PURPOSE / INTERACTION FANTASY

N.O.V.A. 终端。玩家与舰载智能交流，了解下一步行动，查看、追踪个人任务并领取奖励。
交互应像与飞船上的智能同伴联系、操作嵌入式设备。

## SCREEN MODE

Feature UI。通讯页以全息投影为主视觉；任务、资料页以清楚的阅读与操作为主。

## PRIMARY VISUAL

- 通讯：球体、斜轨道与独立眼睛层构成的 N.O.V.A. 投影，与当前答复共同建立重心。
- 任务：当前展开的任务名称、下一步行动、对应的操作。
- 资料：资料标题与正文，不建立第二套卡片网格。

## INFORMATION PRIORITY

1. 正在与谁交流 / 正在查看什么任务。
2. 当前答复 / 下一步行动。
3. 可执行操作。
4. 真实条件、消耗和奖励。
5. 其他话题、其他任务、历史记录。

## INTERACTION FLOW

- 通讯 → 当前答复 → 询问下一步或选择其他话题 → 获得答复。
- 任务 → 选择条目 → 展开操作与条件 → 追踪 / 询问 N.O.V.A.。
- 从任务发起询问 → 通讯页显示对应任务上下文 → 返回同一任务及原滚动位置。
- 已完成任务 → 奖励 → 领取 → 紧凑的已领取状态。
- 锁定任务可阅读前提，不提供追踪/领取操作。
- 重开终端保留上次页面与阅读位置。首次核心恢复、必须关注的剧情事件可明确进入通讯。

## SPATIAL ORGANIZATION

- 单一石墨外壳与顶部模式导航：通讯 / 任务 / 资料。
- 总览中的当前目标并入通讯上下文；待领取奖励进入已完成任务筛选。
- 标准概念尺寸为 560×330；窄窗口检查尺寸为 360×240 逻辑单位。
- 通讯左侧投影区约占内容宽度三成，其余为对话、选项。没有第二条永久导航侧栏。
- 窄窗口保留 8px 正文，收紧间距与投影尺寸；其他话题临时替换答复区供选择，选完返回完整答复。空间不足时滚动，不再缩字。
- 任务与资料使用完整内容宽度。任务只展开一项，任务分组采用文字、对齐和细分隔线。
- 窗口最终尺寸应服从真实屏幕逻辑尺寸，不固定把 560×330 塞入 GUI Scale 4。

## ART / CUSTOM VISUALS

- 沿用 `nova_body.png` 和 `nova_eyes.png`；原图分层、比例、球体与轨道轮廓保持。
- 新外壳依靠钛灰结构边、局部 1px 上亮下暗、内凹内容与有限青色强调建立质感。
- 主按钮使用石墨/暗青实体底、局部青色指示。按下反转边缘明暗，不移动文字。
- 当前概念用 HTML/CSS 验证构图与状态；字体不是 Minecraft 字体的验收结果。
- 制造设备风格只复用边缘、按键状态和色彩角色，不复制打印站结构。

## GENERIC UI

顶部模式导航、平铺任务行、展开区、文字链接、滚动区域、真实奖励图标。
资料页使用同一平铺阅读结构，保留当前已解锁资料和相关任务入口。

## MOTION / FEEDBACK

- 投影只保留轻微漂浮、眨眼、注视和与发言对应的眼睛反馈；概念图使用静态帧。
- 点击在按键明暗与答复更新中反馈，不依靠持续发光或大幅缩放。
- 选中导航与展开任务有常驻青色标记；hover 只适度提亮。
- 完成和已领取使用工程绿；成本使用琥珀；正常操作使用青色。危险和真实故障才使用红色。

## STATES

普通 / 悬停 / 按下 / 键盘焦点 / 选中 / 锁定前提 / 进行中 / 追踪中 / 完成待领 / 已领取。
首次离线、核心重启、同步等待和动作未确认使用相同外壳与文字层级，保持服务端确认边界。

## DO NOT

- 不恢复双侧栏、逐行发光卡片、聊天气泡、宽幅浅绿操作带。
- 不添加虚构舰船代号、投影百分比、版本号、时间或技术日志作为装饰。
- 不以小字或省略号处理关键行动与条件。
- 不在完成任务下保留灰色追踪按钮或无用询问入口。

## IMPLEMENTATION CONTRACT

实现应保持：
- 三页顶部导航、页面的主视觉和空间职责。
- 投影分层、颜色语义、按钮的实体反馈、任务上下文与返回路径。
- 既有玩法条件、任务身份、材料数量与奖励；UI 不改变服务端 authority。

实现阶段可决定：
- LDLib2 树结构、纹理或自绘划分、事件绑定、保留式更新与同步接入。
- 在 GUI Scale 2/3/4 与中英文实机证据下调整尺寸、换行与滚动阈值。

## 验证入口与证据边界

- `./gradlew test --tests "com.starboundmc.client.shipai.*" --tests "com.starboundmc.story.NovaTask*"`：会话、任务导航与既有任务规则。
- `./gradlew runClient -PnovaTerminalSmoke`：独立 run 目录、无世界/服务端的生产 UI 树渲染。覆盖中英文、GUI Scale 2/3/4、当前答复、任务、奖励、锁定、资料、记录、窄窗口话题与离线状态；画面保存在 `run-nova-terminal-smoke/screenshots/`。
- 合成快照和无玩家渲染只验证排布、命中和显示，不证明真实物品奖励、服务端拒绝、多人同步或完整序章。上述实机验收仍在 [current-work](../current-work.md)。
