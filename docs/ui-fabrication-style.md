# 石墨舰载制造终端 — 风格约束 v1

状态：2026-09-22，用户基于体素打印站实机截图认可整体外观，并批准将其形成约束。
本规范固定已认可的视觉语言；该截图不代表所有语言、GUI Scale 和交互状态均已验收。

## 适用范围与优先级

- 体素打印站必须遵循本规范及其[当前设计契约](ui-design-contracts/voxel-printing-station-polish.md)。
- 后续普通制造、加工、资源处理界面可复用组件外观，但须先明确各自的交互和布局。
- 本规范是[项目美术规范](ui-art-direction.md)的制造设备子主题；不要求星图、N.O.V.A.、
  物质枪升级等专属界面复制打印站布局。
- 本规范不授权结构重做。打印站当前 320×240 面板、左右区域、背包与输出槽坐标、队列切换方式、
  字号和命中范围保持不变。旧的 440px 制造舱方案不再是当前界面的实现目标。

## 视觉定位

紧凑、精确、安静的舰载工业设备。通过硬像素边缘、克制的明暗差和清晰的操作状态建立质感。
物品名称与输出槽是内容重点，打印按钮是主操作，配方导航和背包是辅助区域。

## 色彩角色

| 角色 | 打印站基准色 | 约束 |
| --- | --- | --- |
| 外壳 | `#101A22` | 深石墨，保持不透明、稳定的承载感 |
| 标题带 | `#16232D` | 比外壳略亮，不叠加大渐变或高亮描边 |
| 内容区域 | `#0D171F` | 比外壳略暗，以明度差组织区域 |
| 输入凹槽 | `#081116` | 最暗层，用于搜索、数值输入和槽位 |
| 结构边缘 | `#344B55` | 钛灰，区分设备结构与交互强调 |
| 上沿高光 / 下沿阴影 | `#526975` / `#070F15` | 限定为 1 个逻辑像素的边缘 |
| 主要文字 | `#D8EDF0`，重点名称可用 `#E5F3F5` | 冷白；物品自己的稀有度和描述颜色可保留 |
| 次要文字 | 灰蓝，约 `#8AA2AD` | 仍须可读，不以极低透明度制造层级 |
| 选中背景 | `#17343E` | 持久的暗青实底，不能只依赖 hover |
| 交互强调 | `#63D8D4` | 用于选中标记、焦点、活动状态 |
| 主按钮 | `#20545D` | 低饱和青色实底，hover 为 `#2C6B73` |
| 材料不足 | `#E2B66F` | 只强调缺口数量；满足需求时使用普通冷白 |
| 悬浮框 | `#F8101A22` | 石墨底；钛灰边，取消默认紫色边框 |

上述颜色代表语义，不能将所有可交互区域统一点亮。工程绿只用于明确的完成反馈，
不将整列满足条件的材料数字变绿。红色只用于真实错误或危险。

## 组件外观

| 组件 | 必须保持的特征 |
| --- | --- |
| 外壳 | 硬边、细钛灰轮廓、轻微上亮下暗；装饰集中在外沿 |
| 搜索与数量输入 | 暗底内凹、常驻可见底线；聚焦时有青色指示 |
| 分类选择器 | 薄型实体控件，统一单色像素符号和小箭头 |
| 配方列表 | 平铺行，无逐行卡片框；选中为暗青填充加左侧青色标记 |
| 材料行 | 图标、名称、右对齐数量；仅使用弱分隔线，不增加背景卡片 |
| 数量按钮 | 紧凑分段控件，轻微凸起；数字输入与按键在视觉上可区分 |
| 打印按钮 | 明确的青色主操作，有上沿高光和下沿阴影；按下反转明暗 |
| 输出与背包槽 | 暗色内凹；输出框可略强，背包保持中性 |
| 滚动条 | 平直钛灰滑块，灰蓝像素箭头；hover 青色，pressed 冷白 |
| 队列 | 普通行平底，活动行暗青底加侧标记；与配方列表共用状态语言 |
| 悬浮提示 | 真正的多行文本，保留文字样式；石墨底和钛灰边，不显示换行控制符 |

滚动箭头需按实际可用宽度绘制。当前滑轨仅 3 个逻辑像素宽，不能将通用 6px 图标直接塞入。
所有装饰应在原有组件边界内绘制，不挤占文本、修改命中范围或覆盖物品内容。

## 状态与信息层级

- 默认：清晰但安静；按钮和输入框在点击之前即可辨认。
- 悬停：仅小幅提亮，强度低于持久选中。
- 选中：背景与标记持续可见；即使材料不足，选中名称仍使用清晰的冷白。
- 按下：通过边缘明暗反转表达深度，不移动布局。
- 禁用：背景与文字降强度，但保持可读，并在提示中解释原因。
- 缺材料：配方仍可选，不能将整行做成禁用外观。
- 焦点：输入框显示青色指示，键入内容不被刷新覆盖。
- 动效：只表达状态或进度；不增加持续呼吸、闪烁、粒子或扫描背景。

保留现有标题、物品名称、正文和辅助数据的字号层级。空间不足时先处理裁切与完整提示，
不靠继续缩小文字塞入更多内容。物品图标保留原有彩色像素资产；功能符号采用单色硬像素轮廓。

## 禁止的风格漂移

- 每个分组增加矩形卡片、嵌套面板或独立发光边框。
- 大圆角、玻璃模糊、大面积渐变、随机划痕和无意义螺丝装饰。
- 用更多青色、更多网格或更多动画替代清晰层级。
- 混用默认紫黑滚动箭头、紫色悬浮框与这套设备皮肤。
- 因公共组件或框架使用方便，改变已认可的布局、槽位或操作顺序。
- 将这套制造设备配色强制覆盖其他系统的专属视觉身份。

## 实现与验收

- `voxel_printing_station.lss` 管理填充、文字和状态色；`PrinterUiSkin` 管理打印站局部边缘与符号。
- 悬浮文本中的显式换行在交给 tooltip 前拆成独立 Component 行，保留继承颜色等样式。
- 悬浮框皮肤只在打印站屏幕生效，不全局改变 Minecraft 或其他机器提示。
- 复用外观时沿用本规范的语义；技术抽象应跟随实际复用需求，不为统一而重写功能组件。
- 检查中英文、GUI Scale 2/3/4、默认/悬停/选中/禁用/焦点，以及缺材料、打印、产出、队列状态。
- 检查长名称和多行提示无控制符、无溢出；滚动箭头、滑块和下拉选项均使用统一皮肤。
- 编译和自动测试不能代替实机视觉验收；用户已认可的截图作为本版观感基线。
